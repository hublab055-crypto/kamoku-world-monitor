## 1. ゲームの方向性

Frontier World は、2D の開拓生活シミュレーションを中心に、RPG、家族・世代交代、クラフト、戦闘、農業、住民AI、自動行動（ガンビット）を統合するゲーム。

中心ループは次の通り。

- 資源を集める
- 野営地を発展させる
- NPC と関係を築く
- 仲間へ仕事を任せる
- 家・家具・生活設備を作る
- 料理・道具・衣服・装備・アクセサリーを制作する
- 畑、狩り、釣り、戦闘、訓練を行う
- 結婚・出産・育児・成長・継承を通じて世代をつなぐ
- プレイヤー/NPCの予定表と自動行動で生活を自律化する

## 2. 現在の主要キャラクター

- Mio: 採集・料理寄り。表情、瞬き、口パクあり。
- Riku: 採集・制作・建築寄り。
- Guard: 警備、巡回、剣・弓訓練。
- Shop / Merchant: 売買、農業用品、レシピ本。
- Player: 操作キャラ。家族・忠誠の高い人物へ操作権を移せる。
- Children: 赤ちゃん → 少年/少女 → 成人。成人後は結婚・家族拡張の対象。

  - 🗄️ 棚
  - 🪑 食卓
- 室内の予定行動は対象家具/設備の位置へ移動してから実行する。
- 家具配置換えモードでは通常の室内タップ移動と入力を分離し、ベッド・ベビーベッド・生活設備・チェスト・食卓・椅子・暖炉を直接ドラッグ移動できる。
- ドラッグ完了時は位置を1/4マス単位で確定する。
- 家具撤去モードでは撤去対象を1つタップして削除できる。赤ちゃんが使用中のベビーベッドは安全のため撤去不可。
- V34 で家族/NPCの室内家事を実際の室内状態として管理し、プレイヤーが屋外へ出ても料理・掃除・洗濯などを室内で継続する。

- V34.1 で家族の予定表を受動的な `homeWait` より優先し、余暇・家事等で室内を移動するよう修正。
- 家具・設備ごとに清潔度 0〜100 を持つ。対象はキッチン、食卓・机、トイレ、風呂、ベッド、ベビーベッド、タライ。
- 料理、食事、トイレ、風呂、日常経過で清潔度が低下し、掃除で回復する。
- 掃除AIは最も汚れている家具・設備へ実際に移動し、順番に清掃する。食卓の食器汚れも掃除対象に統合する。
- 洗濯は 1 回につき水 1 を消費し、「タライで洗う → 屋外へ運ぶ → 物干し → 乾燥 → 取り込む → 室内で畳む → 棚/チェストへ収納」の工程を順に実行する。

### 雇用・日給・忠誠（V32）

実装済み。

- Merchant を除く会話対象NPCを、会話の「💼 雇う」から日給制で雇用できる。
- 雇用開始時に初日の日給を前払いし、その日から既存の採集・料理・制作・建築などの仕事指示を利用できる。
- 日付が変わるたびに給料を自動支給する。
- 日給は固定値ではなく、本人の「職能Lv」と現在のスキル値で再計算する。
- 現行式: `max(4, round(4 + 職能Lv×1.5 + 上位2スキル合計×1.25 + 役割補正)) G/日`
- 役割補正の初期値: Guard +2G、Gatherer +1G、Family +1G。
- 給料が当日分まで支払われている間、忠誠心は最低75を保証する。友好・家族・プレゼント等で75を超えることはできる。
- 給料を払えない日は、その日の日給を未払い賃金として記録し、忠誠心が12低下、仕事は停止する。
- 未払い中は追加の日給を積み上げず、未払い分を精算するとその日から仕事へ復帰する。
- 契約終了後も未払い賃金が残っていれば精算可能。
- 給料を支払った日数で職能XPを獲得し、`職能Lv×10 XP` ごとに職能Lvが上がる。レベル上昇は次回以降の日給へ反映される。
- 雇用情報は `npc.employment`、給与履歴・最終給与処理日は `state.employment32` に保存する。
- 旧セーブには雇用データを自動補完し、過去日に遡って給与を請求しない。
- 給与原資は既存の `state.player.coins` を使用し、雇用UIでは G と表示する。


### 商人雇用・会社買収（V33）

実装済み。

- 商人との会話に「🏢 商売・会社」を追加。
- 「商人を雇う」と「会社を所有する」を別契約として扱う。
- 商人だけを専属契約して、既存会社の交易手数料を得ることができる。
- 商人の日給は通常雇用とは別に商人向け最低8G/日とし、職能Lv・交易を含むスキルから再計算する。
- 商人が専属契約中でも店頭に残り、通常の商売NPCとして行動する。
- 商人の会社 `Frontier Trading Company` を資金が十分なら買収できる。
- 会社買収後は店舗・会社資金・信用・利益履歴を引き継ぐ。
- 会社所有と商人雇用は独立しているため、以下を選べる。
  - 商人だけ雇う
  - 会社だけ買う
  - 会社を買い、商人を店長/管理者として雇う
- 自社を商人なしでも経営できるが、営業効率は低下する。
- 商人を雇っていると交易Lvに応じて売上効率が上がる。
- 会社は日ごとに売上・運営費・純利益を計算し、会社資金へ反映する。
- 商人所有会社で商人を専属契約している場合、売上の一部を交易手数料としてプレイヤーへ支払う。
- プレイヤー所有会社では商人の日給を会社資金から支払う。独立会社の商人契約はプレイヤー個人資金から支払う。
- 通常の店頭売買、農業用品、レシピ本、制作物売却を会社資金の入出金へ連動する。
- 会社所有後は個人資金から会社への出資、会社資金からの引き出しが可能。
- 会社は後から売却可能。売却価格は企業価値の約85%。
- 企業価値は会社資金、直近利益、信用を基礎に動的計算する。
- 商人・会社データはセーブ対象で、旧セーブでは `state.commerce33` を自動補完し過去日の商業損益は遡及計算しない。

## 12. 自動行動 / 🤖🤔 ガンビット

実装済み。現在の中核システム。

UI:
- 🤖 固定ON/OFFボタン。
- 🤔 固定設定ボタン。🤖の隣に配置。
- 🤔で条件付き自動行動スロット設定を開く。

スロット:
- 初期 4 枠。
- 自動行動Lvが5上がるごとに1枠解放。
- 最大 10 枠。
- 上から優先度順に判定。
- V34 では数値条件ごとに比較演算子を選択可能: 未満 / 以下 / 同じ / 以上 / より大きい / 以外。
- 旧セーブの条件は従来の意味を保つよう自動変換する（例: スタミナ以下→「以下」、重量以上→「以上」）。
- 家の清潔度を数値条件として利用でき、「清潔度70以下なら家を掃除する」等を設定可能。

代表行動:
- 最寄り資源採集
- 木 / 水 / 石 / 食料
- 畑
- 運搬
- 会話
- 赤ちゃんの世話
- 敵と戦う
- 狩り
- 釣り
- 巡回/防衛
- 休息
- 剣訓練
- 弓訓練
- 植林
- 畑作成
- 種まき
- 水やり
- 施肥
- 草抜き
- 収穫
- 食料を食べる
- 家を掃除する

条件例:
- 常に
- スタミナが以下
- 満腹度が以下
- HPが以下
- 共通備蓄の食料/水/木/石が未満
- 何か持っている
- 持ち物重量が○kg以上
- 赤ちゃん欲求が以下
- 範囲内に敵がいる
- 昼 / 夜
- 範囲内に木がない
- 畑数が未満
- 畑の各作業条件

ヒステリシス:
- 「開始しきい値」と「終了値まで継続」を分離。
- 例: スタミナ30以下で休息開始 → 100まで休息を継続。
- 上位優先スロットの緊急行動は途中割り込み可能。

行動範囲:
- 中心座標と半径を指定。
- MAX半径は自動行動Lvで増加。

## 16. 会話システム

実装済み。

- 関係性別セリフ。
- 呼称変化。
- NPCからプレイヤーへ話しかけてくる。
- 初対面では自己紹介。
- 備蓄不足、危険、制作完了、家族イベントなどを理由にNPCから接近して会話。
- 会話キャッチボール。
- 好きなもの、未来、気分、家、思い出、夢、食事、心配事、天気等の質問。
- 回答を記憶する conversationMemory。
- 好きなものへの回答後、NPCからプレゼントされることがある。
- 親しいNPCからレシピ本をプレゼントされることがある。
- プレゼントした時は関係性に応じて「ありがとう」等の反応。
- セリフウィンドウはキャラ窓・名前・本文を固定表示し、選択肢部分のみスクロールする。

別チャットでセリフを増やすための共有ファイル:
- `frontier-world/data/dialogue-pack.json`

注意: 現在のゲーム本体はセリフを主に `index.html` 内にも保持している。dialogue-pack.json は **共同編集用の外部ソース** として作成し、今後メイン実装側で同期/ローダー統合する。

## 18. 家族・出産・育児・成長

- 欲求:

  - おむつ
  - お風呂

### Creator Suite 画像保存

画像バイナリはプロジェクトJSONに埋め込まず、IndexedDB `frontier-world-creator-assets` に保存する。削除操作は `deletedAt` を付与する論理削除とし、ゴミ箱から復元可能。完全削除はゴミ箱内から明示実行した場合のみ行う。


### Creator Suite GitHub直接編集

実装済みUI/クライアント機能:

- Supabase Auth経由のGitHub OAuthログイン
- 対象repoを `hublab055-crypto/kamoku-world-monitor` に固定
- `frontier-world/` 配下のGitHubファイル一覧・読込
- テキストファイルの新規作成・編集・簡易差分確認・commit

- 読込時SHAを使った更新競合検出

- 編集PNGを元GitHubパスへcommit
- GitHub provider tokenはsessionStorageにのみ一時保持

設定値は `frontier-world/editor/GITHUB_AUTH_SETUP.md` に記載。
