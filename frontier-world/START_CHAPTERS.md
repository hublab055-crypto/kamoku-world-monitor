# 開始物語の選択（START_CHAPTERS）

## 操作フロー
1. トレードマーク画面からタイトルへ進む。
2. 「はじめから」を押すと開始地域／物語の一覧を表示する。
3. 地域カードを選択すると概要と提供状態を確認できる。
4. プレイ可能な地域のみ「この物語ではじめる」が有効になる。
5. 既存セーブがある場合、新規開始前にオートセーブ上書きの警告を表示する。
6. 「戻る」／Escでタイトル画面に戻れる。「つづける」「設定」は変更しない。

## 実装範囲
- 2026-10-14: タイトル「はじめから」から物語一覧を開き、現在の開拓編を開始可能にした。
- 将来編は構想のプレビュー。現行マップ・NPC・イベントはまだその地域向けに作られていないため、開始ボタンは無効。未実装地域で現行ゲームを誤起動しない。
- 選択したプレイ可能な編IDを `window.__fwStartingChapter` に公開し、最後の選択を `localStorage.frontier_world_start_chapter_v1` に記録する。現状は `frontier` のみ開始可能。
- **注意**: これらは将来の地域別初期マップ・NPC・物資・シナリオに接続するための導入UI。保存スロットごとの地域ID永続化、地域別初期状態生成、地域移動、編固有の開始イベントは未実装。
- 選択できるだけで未制作地域をプレイ可能と表示しないこと。

## 将来の実装契約
- 地域定義を外部のバージョン付きデータに分離する。
- 地域別に初期位置、開始年代、主人公、文化、建築、資源、家族・仲間、導入イベントを宣言する。
- ゲームエンジンが地域別の初期状態を生成できた編だけ `available:true` とし、UIと実状態を同期する。
- 新しいセーブのメタデータに開始地域IDを保存し、「つづける」で地域名を表示する。
- 既存セーブに地域情報がなければ互換上 `frontier` として扱う。

## 動作確認観点
- 「はじめから」→地域選択→「開拓編」→既存の新規ゲーム開始が動作する。
- 7地域の詳細が表示され、未実装編で開始ボタンが押せない。
- 「戻る」とEscでタイトルへ戻れる。
- キーボードTab／Enter／タッチ操作が使え、選択状態がわかる。
- 続きのセーブ選択やタイトルテーマA/B/Cの設定は従来通り利用できる。
