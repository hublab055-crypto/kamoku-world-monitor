# Frontier World — オルガン / MIDI試験機能（FW48）

追加日: 2026-10-12

## 機能
- コモンハウス（初期建物 `house1`）にオルガンを初期配置。室内に表示。近付いて「🎹 オルガンを弾く」または⚡で演奏画面を開く。
- 室内のインベントリから、家具を現在位置に再配置／収納。
- 司祭エリアスの会話メニュー「🎼 楽譜庫・オルガン演奏」から演奏ページを開く。
- 司祭NPCはゲーム内時刻12:35〜13:45の間、コモンハウス内で演奏中の状態と音符の演出を持つ（**演出のみ**。村全体へ自動音声配信は未実装）。
- `organ/index.html`：C4〜C6の25鍵相当、Web Audioでオルガン音を合成、複数同時押し可能、録音・段階入力・音符取り消し・再生。
- 録音／段階入力を五線譜（ト音記号4/4）へ簡易変換。楽譜PNGの書き出し。
- 標準MIDIファイル（SMF Type 0、480 PPQ、単一トラック、Program Change=19の教会オルガン）に書き出し。
- 演奏作品をブラウザのローカルストレージ `fw_frontier_organ_scores_v1` へ保管（最大80曲、1曲最大512音）。
- 初期曲「朝の祈り」（司祭エリアス作・試演用）と、保存済み曲の試聴・再編集・削除。

## 確認手順
1. `frontier-world/organ/` に直接アクセス。鍵盤をタッチして発音を確認する。
2. 「⏺ 録音開始」→数鍵演奏→「⏹ 録音終了」→楽譜を確認。
3. 「📜 司祭に保管」→楽譜庫に表示→「▶ 聴く」で再生→再読込後も残ること。
4. 「⬇ MIDI書き出し」→MIDIファイルをDAWで開き、テンポ・音程・長さを確認。
5. ゲームに入り、コモンハウスでオルガンを表示・演奏。司祭メニューからも同じ楽譜庫を開けること。
6. コモンハウス室内のインベントリでオルガンの収納・再配置を試す。
7. ゲーム時刻12:35〜13:45に司祭の状態を確認。

## 制限と今後
- 音声はiOS Safariなどのブラウザ方針により最初のユーザー操作が必要。
- MIDI**出力**は対応。外部MIDI読込、ペダル、複数トラック、印刷用に整った出版譜への変換は今後。
- 楽譜保管は端末ごとのブラウザ内であり、ゲームセーブ、Supabase、他端末へはまだ同期しない。
- 楽譜表示は簡易版。声部分離・連桁・和音・休符・臨時記号など正式な記譜規則は未実装。
- 司祭はゲーム内で演奏動作・状態が表示され、曲を実際に聴くにはオルガン画面で「司祭の演奏を聴く」を押す。
- 実ブラウザでの音声・画面操作テストは未実施。GitHub側でスクリプト構文チェックを実施。

## 2026-10-12: FW48.3 司祭・NPCの楽譜習得と行事演奏

- 司祭エリアスの会話に「🎶 司祭の音楽室・演奏を依頼」を追加。
- 音楽室：司祭の習得済み曲一覧、試聴、婚礼曲・村祭り曲の個別指定、1日1回の楽譜収集、NPCへの演奏指導。
- 楽譜収集は登録済みパブリックドメイン練習曲から未習得のものを追加（1日1回、全曲収集済みなら終了）。
- プレイヤー作曲・録音した楽譜はオルガンの「司祭に保管」で保存され、司祭も習得。「⛪ 司祭に教える」で既存曲を教えられる。ゲーム内iframeとの連携は同一オリジン・現在のiframe発信元のみ受信し、曲名・音符データを検証する。
- 司祭の習得曲とNPCの習得済み曲IDはゲームの既存セーブに保持。オルガン楽譜庫・習得曲データはブラウザのlocalStorageにも保持。端末間クラウド同期は未実装。
- 司祭NPCはコモンハウスで12:35〜13:45に、その日の習得済み曲を練習中と表示（視覚・状態表現）。自動的な環境音再生ではない。
- 指定NPCは司祭が習得済みの楽譜を覚えられる。結婚式／村祭りでは曲を覚えたNPCがいれば演奏者として選ばれ、イベント記録に曲ID・曲名・演奏者を保存。該当するNPCがいなければ司祭が演奏者となる。
- 結婚式／村祭りの開催時はWeb Audioで該当曲を試演。音声再生はブラウザのユーザー操作条件に依存し、iOSで自動的に鳴る保証はない。音が出ない場合、司祭の音楽室で明示的に「▶ 演奏」を押す。
- 新規ソース: `organ/priest-music-bridge.js`。楽譜定義は引き続き `organ/public-domain-catalog.js`、プレイヤー音楽工房は `organ/index.html`。従来のオルガン、MIDI/PNG出力、司祭メニュー等は維持。
- 検証: JavaScriptの構文確認、模擬AudioContextとNPC・ゲーム状態による17項目（収集制限、習得、イベント選曲・演奏者、復元、音声スケジュール等）全項目成功。Safari実機での音声・UI最終検証は未実施。

## 2026-10-12: FW48.5 多楽器音楽工房／ループ再生／PDレパートリー拡張

### 機能
- 独自 Web Audio 音色エンジン `instrument-engine.js` を実装。11音色: パイプオルガン、ギター、バイオリン、リュート、尺八、フルート、トランペット、サックス、和太鼓、タブラ、ドラムセット。外部サンプルや録音音源は使わず、波形・倍音・ノイズ・包絡線から軽量に近似する。実楽器と完全に同じ音にはならない。
- 楽器選択を鍵盤演奏・録音楽譜・楽譜庫のロード・再生・MIDI出力・司祭の演奏に連携。既存楽譜は未指定ならオルガンで再生。
- オルガン工房の「🔁 繰り返し再生」は無期限ループでき、「■ 停止」で中断可能。ループ設定はブラウザのlocalStorageにも保存。新しい楽器を選ぶと演奏は停止し、新しい音色の選択状態になる。
- 司祭の音楽室にも「🔁 演奏を繰り返す」を追加。結婚式・村祭りは行事が無限ループしないよう、1回再生のまま。繰り返し設定はゲームセーブ内に保持。
- ドラムはC4〜C6鍵盤25個をGM標準の打楽器音（MIDIノート35〜59）に割り当て、C4=キック、D#4=スネア、G4=ハイハット、D5=シンバル等。タブラはボンゴ・コンガ相当のMIDI音にマッピング。両者はMIDIチャンネル10を使用。
- MIDIは1トラックのSMF Type 0で、通常楽器はGeneral MIDI Program Change、打楽器はチャンネル10（チャンネル番号9）に出力。リュートはナイロンギター音、タブラはコンガ／ボンゴ音の近似であり、完全再現ではない。
- 新しい楽曲を7曲追加し、初期楽譜5曲+司祭初期曲1曲と合わせて13曲。追加: フレール・ジャック、ジングルベル（サビ抜粋）、ロンドン橋、ホット・クロス・バンズ、グリーンスリーブス（抜粋）、さくらさくら（抜粋）、月の光に（Au clair de la lune）。伝承曲・著作権満了曲の旋律から入力した練習用簡易譜で、現代の編曲や既存録音は収録しない。出典URL・権利注記を各曲に表示。
- 各初期楽譜に試聴に向いた推薦楽器を紐づけた。楽譜庫から「📖 開く」を押すと楽器を変更でき、「▶ 聴く」で現在選択中の楽器音色でも試聴可能。

### 自動テスト結果
- 11種類の楽器それぞれの発音・離鍵処理を模擬AudioContextで検査。
- 12曲の初期パブリックドメイン練習譜について、C4〜C6の音域およびデータ形式を検証。
- 通常楽器（バイオリン）のMIDIプログラム番号40、ドラム／タブラの打楽器ch10・対応ノートを検査。
- オルガンの繰り返し再生（複数周回）と停止後の再発音なしを模擬時計で検証。
- 司祭の曲の習得、楽器設定引き継ぎ、NPCへの指導、行事演奏は1回のみ、音楽室のループチェック項目をテスト。音楽工房11項目、司祭・NPC側11項目がすべて成功。
- 未検証: iOS Safariでの実音・実タッチ操作。再生音は端末／スピーカーによって印象が異なる。

### 手動テスト
1. `frontier-world/organ/?fwfix=48.5` を開き、楽器を一つずつ選んでC4〜C6鍵盤を弾く。長押し解除で消音し、文字選択が起こらないこと。
2. 「フルート」を選び、楽譜庫の曲を「▶ 聴く」で再生。🔁をオンにして2周以上再生し、■停止で止まること。
3. 「ドラムセット」と「タブラ」を選び、鍵盤の打音差を聞く。録音・保存後にMIDIを開き、打楽器ch10となっていることを確認。
4. ギターや尺八を選んだ状態で録音・保存。楽譜庫から再度開くと同じ音色が選択されること。
5. ゲームの司祭エリアスの音楽室で曲を覚える、NPCへ教える、演奏する、ループをオンオフする。結婚式／村祭りで指定曲と演奏者が残り、無限ループしないこと。
