# Frontier World — オルガン / MIDI試験機能（FW48）

追加日: 2026-10-12

## 機能
- コモンハウス（初期建物 `house1`）にオルガンを初期配置。室内に表示。近付いて「🎹 オルガンを弾く」または⚡で演奏画面を開く。
- 室内のインベントリから、家具を現在位置に再配置／収納。
- 司祭エリアスの会話メニュー「🎼 楽譜庫・オルガン演奏」から演奏ページを開く。
- 司祭NPCはゲーム内時刻12:35〜13:45の間、コモンハウス内で演奏中の状態と音符の演出を持つ（**演出のみ**。村全体へ自動音声配信は未実装）。
- `organ/index.html`：C4〜C6の25鍵相当、Web Audioでオルガン音を合成、複数同時押し可能、録音・段階入力・音符取り消し・再生。
- 録音／段階入力を五線譜（ト音記号4/4）へ簡易変換。楽譜PNGの書き出し。
- 標準MIDIファイル（SMF Type 0、480 PPQ、単一トラック、Program Change=19の教会オルガン）に書き出し。
- 演奏作品をブラウザのローカルストレージ `fw_frontier_organ_scores_v1` へ保管（最大80曲、1曲最大512音）。
- 初期曲「朝の祈り」（司祭エリアス作・試演用）と、保存済み曲の試聴・再編集・削除。

## 確認手順
1. `frontier-world/organ/` に直接アクセス。鍵盤をタッチして発音を確認する。
2. 「⏺ 録音開始」→数鍵演奏→「⏹ 録音終了」→楽譜を確認。
3. 「📜 司祭に保管」→楽譜庫に表示→「▶ 聴く」で再生→再読込後も残ること。
4. 「⬇ MIDI書き出し」→MIDIファイルをDAWで開き、テンポ・音程・長さを確認。
5. ゲームに入り、コモンハウスでオルガンを表示・演奏。司祭メニューからも同じ楽譜庫を開けること。
6. コモンハウス室内のインベントリでオルガンの収納・再配置を試す。
7. ゲーム時刻12:35〜13:45に司祭の状態を確認。

## 制限と今後
- 音声はiOS Safariなどのブラウザ方針により最初のユーザー操作が必要。
- MIDI**出力**は対応。外部MIDI読込、ペダル、複数トラック、印刷用に整った出版譜への変換は今後。
- 楽譜保管は端末ごとのブラウザ内であり、ゲームセーブ、Supabase、他端末へはまだ同期しない。
- 楽譜表示は簡易版。声部分離・連桁・和音・休符・臨時記号など正式な記譜規則は未実装。
- 司祭はゲーム内で演奏動作・状態が表示され、曲を実際に聴くにはオルガン画面で「司祭の演奏を聴く」を押す。
- 実ブラウザでの音声・画面操作テストは未実施。GitHub側でスクリプト構文チェックを実施。

- 2026-10-12 FW48.1: 指を離した後も音が鳴り続ける問題に対応。タッチ終了・キャンセルを画面全体で検出し、マウスの離鍵・フォーカス喪失・画面非表示でも消音。発音を指／キー別に追跡し、和音・同音重ね押しでも音の停止判定を独立化。ゲーム内iframeは `?fwfix=48.1` で修正版を読み込む。
- 検証: 埋め込みJavaScript構文検査通過。模擬入力で単音・同時押し・個別離鍵・touchcancel・mouse pointerup・blurの消音を確認。iPhone Safari実機での再テストは未実施。

## 2026-10-12: FW48.2 パブリックドメイン曲集

- 新規ファイル: `public-domain-catalog.js`。著作権の保護期間が満了した伝統的な旋律やクラシック音楽を元に、ゲーム用に入力した5つの簡易単旋律譜を収録。
- 追加曲: きらきら星（全曲練習用）、歓喜の歌（第九の主題抜粋）、アメイジング・グレイス（抜粋）、蛍の光の原曲 Auld Lang Syne（抜粋）、メリーさんのひつじ（練習曲）。
- 楽譜庫から「📖 開く」「▶ 聴く」で編集・試聴できる。開いた後は従来のMIDI／PNG書き出し機能を使用できる。各楽曲に作者・原曲の権利情報・参照資料URLを表示する。
- 参照元: IMSLP（第九・フランス古謡）、Hymnary.org（NEW BRITAIN／Auld Lang Syne）、Wikimedia Commons（19世紀の童謡資料）。※それぞれの参照ページにある任意の現代編曲の利用許諾を意味しない。
- 商用配布に際しては原曲が日本でパブリックドメインであることに加え、特定の**譜面、編曲、写真、録音**の権利も別個に確認する。CC BYは出典表記などライセンス条件を満たせば利用可能、CC BY-NCは商用アプリでは原則不可。
- 楽譜は独自入力した学習用単旋律であり、現代の編曲譜・録音物は取り込んでいない。全曲の完全な原典版ではないため、抜粋・簡易譜との表示を維持する。
- チェック結果: 5曲の音符数・音程がC4〜C6に収まること、開始位置と音長が有効であること、ブラウザJavaScriptの構文を確認済み。実機音源・実機GUIは未検証。
