## V32 — 2026-10-05 JST — NPC雇用・日給・忠誠

管理ID: `FW-2026-10-04-001`  
ゲーム実装コミット: `db7f05e5c1365461ed6d93e23a90e546584195e2`  
初期実装コミット: `2558be3258d5f6e9fc255c637f249920666b57b1`

### 追加
- NPCを日給制で雇用できる会話メニューを追加。
- 雇用開始時に当日分の日給を前払い。
- 日付変更時に給与を自動支給。
- 職能Lvと上位スキルに応じた日給再計算。
- 給料支払い中の忠誠心最低保証（75）。
- 給料不足時の未払い記録、忠誠低下、作業停止。
- 未払い賃金の精算と作業復帰。
- 職能XP / 職能Lv。
- 給与履歴を最大50件保持。
- 雇用状態をセーブデータに保存し、旧セーブへ自動補完。

### 既存システムとの統合
- 採集、料理、制作、建築など既存の仲間向け仕事処理を再利用。
- 雇用は友好・恋愛・家族関係とは別の契約情報として保持。
- 給与原資は既存の `state.player.coins` を使用。

### 修正
- 契約終了時、雇用前から仲間ではなかったNPCに一時付与した仕事指示権限を解除し、友好・恋愛・家族などの人間関係は保持する。

### 互換性
- 旧セーブ読込時は `npc.employment` と `state.employment32` を自動生成する。
- 旧セーブ以前の日付へ遡った給与請求は行わない。
- Merchant は現段階では雇用対象外。

### 既知の残件
- 雇用UIは `G`、既存ショップの一部は `C` 表記のため、通貨表示の統一が必要。
- 給与交渉、月給、出来高払い、住居・食事込み契約は未実装。

### 追加
- 商人との専属雇用契約。
- 商人契約と会社所有を独立管理。
- Frontier Trading Company の企業価値・会社資金・信用・日次損益。

- 競合企業、倒産、敵対的買収。


## V34 — 2026-10-05 JST — 室内家事・清潔度・洗濯工程・条件比較

管理ID: `FW-2026-10-05-001`  
ゲーム実装コミット: `f99c55e7eb34d859efbdf9e600642b031b41b630`  
初期実装コミット: `272c5ba59e3da8a550666650c1e7555c6104498a`

### 修正
- 家族/NPCの料理・掃除・洗濯・睡眠・入浴などを、家の入口に立った屋外座標で処理する旧挙動から、実際の室内タスクへ移行。
- プレイヤーが家から出ても、室内家事中のNPCを屋外へ強制排出しない。
- 「料理を作って」の直接依頼も室内キッチン/作業場所まで移動して完了するよう統合。
- 自動行動キャラの移動速度を操作キャラの自動移動に近い 3.05 へ引き上げ。

### 追加
- キッチン、食卓・机、トイレ、風呂、ベッド、ベビーベッド、タライごとの清潔度 0〜100。
- 日常使用・経過による汚れと、汚れた設備を順番に掃除するAI。
- 会話指示「🧹 家を掃除して」「🧺 洗濯して」。
- 洗濯工程: 水1消費 → タライ洗い → 屋外へ運搬 → 物干し → 乾燥 → 取り込み → 畳む → 収納。
- 家の清潔度を自動行動条件に追加。
- 自動行動に「🧹 家を掃除する」を追加。
- 数値条件の比較演算子を選択可能に変更: 未満 / 以下 / 同じ / 以上 / より大きい / 以外。

### 互換性
- 旧ガンビット条件は型名から従来の比較方法を自動補完する。
- 室内作業の途中状態はセーブせず、ロード後に予定表/依頼から安全に再開する。
- 家具清潔度は旧セーブへ自動補完する。

### 残件
- 洗濯物の乾燥は現在タイマー式。雨・風・気温・日照との連動は今後拡張。

## V35 — 2026-10-05 JST — 株式・配当・段階的買収

管理ID: `FW-2026-10-05-003`  
ゲーム実装コミット: `7f0c61bf8472c6d8105e4446b31bc35f0fd0922d`

### 追加
- 会社を100株へ分割し、1株=1%の持株比率を導入。
- 1株 / 5株 / 10株の部分取得。
- 企業価値連動の1株価格。
- 持株比率に応じた日次配当。
- 51%で経営権取得、100%で完全買収。
- 経営権取得後の配当性向 0% / 30% / 60% / 90% 選択。
- 残り全株への10%プレミアム付き公開買付。
- 株式売却と、持株51%未満への低下による経営権喪失。
- 51%以上で会社への増資。
- 100%保有時のみ会社資金を個人へ直接移動可能。

### V33からの変更
- 「会社を直接購入」は「株式を積み上げて買収」へ置換。
- V33で買収済みならV35移行時に100株保有へ変換。
- 会社支配の判定を `owner` 単独ではなく、持株51%を基準に同期。

### 株主権
- 1〜9%: 株主
- 10〜33%: 大株主
- 34〜50%: 重要株主
- 51〜99%: 経営権
- 100%: 完全買収・100%子会社

### 残件
- 他NPC/企業による株式売買。
- 注文板、出来高、需給による株価変動。
- 新株発行・増資による希薄化。
- 融資・社債・倒産・再建。
- 複数企業ポートフォリオ、持株会社、子会社間取引。
