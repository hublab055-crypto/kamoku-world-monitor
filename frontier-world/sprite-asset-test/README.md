## 2026-10-11: ブラウザ位置調整モード追加

- 対象: `full.html`
- キャラ選択: 既存キャラ / 新しい子どもキャラ
- 表情（9 / 13種）ごとに X / Y / 拡大率を調整
- 歩行（正面・左・右・背面 × 4コマ）ごとに X / Y / 拡大率を調整
- 通常顔と前コマの半透明比較、中心線、足元基準線
- `frontierWorldSpriteAdjustmentsV1` キーにブラウザ内自動保存
- JSON表示、JSONファイル保存、JSON読込、個別/全体リセット

### 操作方法

1. [フル画質テスト](./full.html) でキャラクターを選択
2. 「調整モード」で表情または歩行を選び、対象を指定
3. X/Yおよび拡大率を調整（通常顔・前コマ比較で位置を確認）
4. 「JSONファイル保存」で補正値を出力して共有

データはブラウザ内に保存し、GitHubの画像ファイルには自動反映されません。切り出し済み素材の描画座標とスケールを調整する機能であり、元画像の画素自体は編集しません。
