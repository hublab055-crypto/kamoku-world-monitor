# フロンティアワールド — 架空文明モデル・英雄・梟雄（V52.8）

## 方向性（2026-10-14 決定）

- **史実再現ゲームではない。** 世界の国家・地域・英雄・戦争は架空のものとし、現実の歴史・地理・制度・文化から着想を得て独自の世界へ再構成する。
- **「編」は実在する土地そのものではなく、文明・生活・社会構造・物語の開始モデル（blueprint）。** 一つの共通惑星に複数の文明が存在し、遠征・交易・婚姻・戦争・移住・後継者により変化する。
- 同じモデルを異なる場所に生成できる。複数モデルの混合・分岐・融合を許す。いずれ「はじめから」は主人公・出生や身分・文明モデル・開始地点を選ぶ入口となる。
- 既存の save / localStorage / Web Audio と互換を保つため、**内部IDは移行しない。** 今回は表示名・構想とタイトルBGMを拡充。開始できる本編マップは依然として開拓者編だけ。
- 出典として使う実在の歴史人物・国家の名称、既存作品のキャラクター・台詞・紋章・音源をそのまま登場させない。地理も創作する。
- 北米先住民やマヤなど実在する今日の文化も着想源として扱う場合、複数社会を一枚岩にせず、安易な記号化を避ける。架空化は史実や現代の文化的文脈を学ぶ代わりにはならない。

## 世界を動かす英雄システムの考え方

ユーザーが求めるのは**一騎当千の武勇**と**孔明型の神算**を併せ持つ群像劇。大軍と制度だけでは決まらない歴史にする。

1. **豪傑（一騎当千型）**：個人武勇／士気鼓舞／突破力／危機からの救出／一騎討ち。部隊の陣形と士気を乱す効果は大きいが、疲労・傷・包囲・食糧・天候は無視できない。千人を実際に一人で斬る固定数値ではなく、戦局への劇的な影響を表現する。
2. **軍師（孔明型）**：偵察・地形・風・時間・補給・攪乱・外交を用いた複数段階の作戦。情報の欠落、敵軍師との知恵比べ、部下の遂行能力を考慮する。プレイヤーも作戦を組める。
3. **梟雄／覇王**：野望、権謀、人材登用、外交、内政、危険な賭け。武勇だけでなく組織設計に秀でる。忠誠を得る一方、疑心や過剰な拡張で失脚しうる。
4. **市井の英雄**：名工・発明家・名医・航海士・商人・法官・農政家も都市や国家を救う。戦闘以外のプレイでも世界史に影響できる。

NPCは長所・短所・信念・人間関係・野心・忠誠・成長・故障・怪我・死亡・継承を持つ。
英雄の出現は**固定キャラだけでなく成長・経験と確率によって動的に起こす**。所属、裏切り、登用、亡命、同盟、後世の評判も変わる。
英雄が強くても国家の資源・経済・市民生活・軍の補給を無意味にしない。

## 梟雄の帝国：史実に存在しない新勢力

- **国家：黒曜帝国（仮）** ／ **梟雄：ヴァルガディス（仮）** ／ 異名「灰冠の梟雄」。
- 裸一貫から勢力を広げた、天才軍師を重用する冷徹な覇王。周辺国家はその人材登用と兵站改革を恐れる。
- 強み：戦略の大胆さ、兵站の革新、多様な出自の部将を抜擢する柔軟性。
- 弱み：優秀な家臣への疑心、継承問題、遠征の過剰拡大。
- 黒曜帝国は民族や実在する特定の宗教の悪役化ではない。多様な民が生活する、長所と欠点を備えた一つの**架空国家**。
- BGM曲ID `ost:empire` を維持しつつ表示曲名を「黒曜帝国の進撃」に変更。勢力登場／大遠征／帝都包囲／英雄対峙などへの**自動発火は今後の設計**。
- 黒曜帝国を史実のトルコ・オスマン帝国と一対一対応させない。双海峡帝都編の勢力とも必ずしも一致しない。国家の友敵関係はゲーム内で変化可能。
