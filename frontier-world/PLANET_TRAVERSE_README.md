# Frontier World — 惑星一周テスト v1.0 (2026-10-16)

## URL

- ゲーム本体: https://hublab055-crypto.github.io/kamoku-world-monitor/frontier-world/
- 惑星テスト: https://hublab055-crypto.github.io/kamoku-world-monitor/frontier-world/planet-traverse.html

## 目的と実装範囲

旧来の2D村を壊さずに、緯度・経度・方位を持つ連続した球体惑星の上を歩く最初のテスト環境です。
本テストは**独立した別画面**です。実際の村・住民・建物データを惑星規模で永続的に一体化したものではありません。

- Three.js r180 / SphereGeometry + 頂点カラー/標高による架空の惑星。
- 球体のため地図の東西端・南北端はなく、任意の方角に進めます。
- 歩行は球体中心を回る大円の回転。進行方向を新しい接平面へ平行移動し、極地通過後も方位を更新。
- 地球儀俯瞰（ドラッグ回転・ピンチ/マウスホイールでズーム）と、プレイヤー追従の地表視点を切替可能。
- 赤道で東へ向いて自動で一周し、移動距離がちょうど一周分になれば記録します。
- 小型惑星の半径は32ゲーム単位、赤道周長は 2π×32 = 約201.06ゲーム単位。現実の地球サイズではありません。
- アバターは前の3Dモードからブラウザー内IndexedDBに保存されたGLBを優先使用。GLB未保存の場合は仮のポリゴン人体モデル。
- 男女の切替ボタンを持ち、男女GLBを別々に読み込む。
- マップ状態はLocalStorageの frontier-planet-traverse-v1 に保存し、既存の村のセーブを変更しない。
- 惑星内の開拓キャンプは2つの仮テントと火の簡略ランドマーク（既存建築状態と未同期）。

## 操作

1. メインゲーム画面の「🪐 惑星一周テストへ」を開く、または惑星テストURLを直接開く。
2. 「🌍 全景」は惑星全体、「🚶 地表」はアバター視点。
3. スマホは画面下の▲▼◀▶を長押し。PCは W/S（前後）・A/D（旋回）、矢印キーも対応。
4. 「🧭 東へ向く」「🧭 北へ向く」で方位を設定。
5. 「🌐 一周テスト」を選択すると赤道の出発地点から自動で東回り一周する。途中停止は「■ 停止」。
6. 「⌂ 出発地」で緯度0°経度0°のテストキャンプへ戻る。
7. 「♂/♀ モデル」でキャラクターの男性・女性モデルを切替。
8. 「✕ 村へ戻る」で元ゲームに戻れる。

## 数値検査

2026-10-16: リポジトリのplanet-traverse.html内の球面移動関数を抽出して関節API不要の数学テストを実施。

- 赤道一周512ステップ後：緯度誤差3.77e-16 rad、経度誤差1.44e-14 rad、方位誤差0。
- 北緯89°から北向きに4°進む：北緯約87°、経度180°、向き180°へ遷移。
- 任意の起点（北緯38°, 東経127°, 方位63°）から大円を512ステップで一周：3D座標差約1.12e-14、方位差0。
- モジュールJSの構文検査は成功。

これらは**球面運動ロジックの単体テスト**です。実ブラウザーのGPU描画、FPS、iPhoneでのタッチ操作、GLBの実描画は未検証です。

## 制限・今後の開発

- この惑星は小型の3Dテスト地形。現在の開拓キャンプ・村・室内・生活イベントと惑星座標を一体化していません。
- 海上も通行できる、衝突・海上移動・船舶・水泳などの物理法則は未実装。
- 現段階では全球を1メッシュで描画。大陸・海底・川・道路・村のストリーミングLOD、クアッドツリー、浮動小数点の局所原点化が必要。
- Universal ENGINEと地形・施設・国家の座標を共通化するには、惑星ID、緯度・経度・高度、永続地形チャンク、データ互換スキーマが必要。
- アバター50k三角形の実モデルバイナリはGitHub未配置。元ゲームの「🌐 3D視点→📦 GLB読込」でモデルを端末キャッシュへ入れた後に惑星テストへ移動すれば同じモデルを読み込みます。
