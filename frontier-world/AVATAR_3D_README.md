# Frontier World 3D Avatar / RTS Bridge v1.0

## 目的

2D版『フロンティアワールド』を残したまま、同じゲーム状態（プレイヤー・NPCの位置、行動状態）を任意で3D表示します。

- **🌐 3D視点**: ゲーム左上のボタンで2D/3Dを切り替える。初期状態は2D。
- **追従 / ⚓ 上空RTS / 自由視点**: カメラ切替。ドラッグで視点回転、ピンチ・スクロールでズーム。
- **NPCの選択**: アバターをタップして選択し、地面をタップすると選択キャラクターに移動指示。PCはShift、スマホは「複数選択」で追加選択。
- **停止 / 🤖 自動**: 選択したNPCの手動指示を停止、または従来のNPC AIへ復帰。3Dを閉じた時も従来のAIへ復帰。
- **♂/♀ 外見**: 選択したアバターの男女モデルを変更。選択がない場合は操作中キャラクターを変更。
- **歩行・生活モーション**: 実際の移動・NPCの状態文字列とGLBのWalk / Idle / Sit / Talk / Chopを連動。
- **GLB / ZIPの読み込み**: 既存のオリジナル3Dモデルパックから男性・女性の実モデルを取り込み。読み込んだモデルは端末のIndexedDBに保存。

## オリジナルの男女GLBを利用する手順

1. 事前に制作した frontier_world_3d_avatars_v1.zip を保存します。
2. ゲームの「🌐 3D視点」を押します。
3. 画面下の「📦 GLB読込」からZIPファイルを選択します。ZIP対応が不安定なブラウザではZIPを展開して frontier_male_mobile.glb と frontier_female_mobile.glb の2ファイルを選択します。
4. 読み込み成功後、男女のオリジナルリグ付きモデルが表示されます。以降同じブラウザでは端末キャッシュを利用できます。

**重要**: この版ではGLB実ファイルはGitHubリポジトリにまだ同梱していません。未インポートの初期状態はコード生成の仮3Dアバターを表示します。初回から正式モデルを配信するには、下記パスへバイナリを追加する必要があります。

    frontier-world/assets/avatars/frontier_male_mobile.glb
    frontier-world/assets/avatars/frontier_female_mobile.glb

同名で配置すると追加操作なしでGLTFLoaderがロードできます。ユーザーのブラウザー側でキャッシュ済みの場合はキャッシュが優先されます。

## 技術設計

- frontier-world/index.html: 既存ゲームのブリッジに setPlayerMove3D(x,y) と canMove3D(x,y) を追加。3DライブラリとJSの読み込みを追加。
- frontier-world/avatar-3d.js: Three.js scene / OrbitControls / GLTFLoader / SkeletonUtils、レンダリング、NPC同期、RTSクリック指示、キャラ別AnimationMixer、IndexedDBキャッシュ。
- 既存ゲームの window.__fwFrontierBridge.state を読み取り、独立したワールド状態を作らない。
- 手動NPC指示中だけブリッジの updateNPC アクセサ経由で移動を処理し、自動復帰時には元の関数へ委譲する。
- 既存のCanvas 2D描画、セーブ処理、バージョン切替、他のウィジェットへの変更は最小限。

## 確認済み・未確認

- **確認済み**: JSの構文解析、GitHubへのコード更新、オリジナルGLB 4ファイルのjoint/triangle/animation構造検査。
- **未確認**: GitHub Pages実端末でのWebGL動作、iOS Safari・メモリ性能、タップ移動の障害物回避、複数端末同期。

- スマホで処理が重い場合、画面上部のボタンでいつでも元の2D描画に戻せます。

## HD50k 高精細モデル v2（2026-10-16）

新規作成のモデルパック `frontier_world_3d_avatars_hd50k_v2.zip` は男性49,876、女性49,930三角形で、8種類のアニメーションと44/46個のジョイントを維持しています。従来の約13k三角形の軽量版を一緒に収録しました。

ゲーム最新版の「🌐 3D視点」から「📦 GLB読込」を選び、ZIPファイルを読み込みます。インポーターは high → rigged → mobile の順にモデルを選び、高精細版を近距離表示で使用し、読み込まれた軽量版をプレイヤーから約11マスより遠いNPCに使用します。モデルは端末のIndexedDBにキャッシュされます。アプリ本体はHD50k対応済みですが、GLBバイナリをリポジトリに直接格納していないため、**初回はZIPの手動読込が必要**です。

静的ビューア・GLB構造検査は済み、ブラウザ実機の3Dレンダリング動作・パフォーマンスは未検証です。Planet/globe mapはこのモデル更新とは別機能です。

## Anatomy v3 — 顔・肩幅改修（2026-10-16）

オリジナルの高精細GLB男女を修正し、3D形状と骨格双方に反映しました（旧版v2は保持）。

- 男性の左右肩位置の基準値: 0.275 → 0.217（各側 約21.1%内側）。
- 女性の左右肩位置の基準値: 0.246 → 0.201（各側 約18.3%内側）。
- 鎖骨、上腕、肘、手、指の座標とウェイトの基準も再生成。ベストと袖の幅も狭め、自然なAポーズを志向。
- 目・瞳・鼻・顎・耳・唇の形状バランスを修正し、浮き上がる頬・髭装飾を除去。
- HD: 男性49,870 / 女性49,890三角形。LOD1: 男性12,892 / 女性13,628三角形。
- 44 / 46個の関節、8つのアニメーションは維持。GLB構造・ウェイト・アニメーションの検査成功。

**読み込み**：ユーザーが配布ZIP `frontier_world_3d_avatars_anatomy_v3.zip` をゲームの「🌐 3D視点 → 📦 GLB読込」へ渡してください。既存インポーターの `frontier_male_high.glb` / `frontier_female_high.glb` と対応する `_mobile.glb` のファイル名を維持しているため、アプリのコード変更は不要です。最新GLBバイナリはGitHubに未同梱で、初回インポートが必要です。

**画質の限界**：3Dの顔はv2より自然な比率へ改良したものの、原型がプロシージャル生成のセミデフォルメモデルであり、写真に近い顔にはまだ達していません。比較画像とフォトリアルな参考コンセプト画像は別物です。

**テスト**：静止レンダリングとGLBバイナリ構造の検証済み。iOS Safariの実動作テスト、ゲーム内でのモーションとLODの連続切替テストは未検証。

## Face30k v5 — 目・口の表情モーフ対応（2026-10-16）

今回、実際のGLBモデルに顔面30,000三角形を維持したまま、2つの表情モーフターゲットを追加しました。

- 男性/女性：各30,000三角形の顔メッシュ、44/46関節。
- `EyeClose`：眼瞼付近の頂点を動かす（閉眼風の変形）。
- `MouthOpen`：唇・顎付近の頂点を動かす（開口風の変形）。
- 追加GLBモーションクリップ：`FaceIdle`（周期的なまばたき）、`FaceTalking`（発話時の口元＋まばたき）。
- 従来の8クリップも維持。新GLBは計10クリップ。
- `avatar-3d.js` に、通常モーション（Idle/Walk等）と並列して顔のクリップを再生するロジックを組み込み。通常はFaceIdle、Talk時はFaceTalking。
- `planet-traverse.html` でもFaceIdleを再生する処理に対応。

**利用方法**：v5の配布ZIP（frontier_world_face30k_expressions_v5.zip）をゲームの「🌐 3D視点 → 📦 GLB読込」で選択し、端末内に保存してください。モデルバイナリはGitHubにまだアップロードできていないため、GitHub Pagesの初回自動ダウンロードは未対応です。ブラウザーからGitHubのリポジトリ内 `frontier-world/assets/avatars/` に `frontier_male_high.glb`、`frontier_female_high.glb` を配置できれば、自動読み込みになります。遠景用の `frontier_male_mobile.glb`、`frontier_female_mobile.glb` も同じ場所へ配置するのが推奨です。

**重要**：正面写真を投影したテクスチャには目・口の元の絵柄が残るため、モーフで変形しても自然な完全閉眼／大きな開口にはなりません。画像1枚からの近似であり、写実的なFACS表情リグや3Dスキャンではありません。iPhone実機でのWebGL再生は未検証です。
