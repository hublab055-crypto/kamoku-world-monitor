## FW-2026-10-04-001 — NPC雇用・日給・忠誠

実装系列: Frontier V32  
対象: `frontier-world/index.html`  
ゲーム実装コミット: `db7f05e5c1365461ed6d93e23a90e546584195e2`

### 仕様上の前提
- 雇用は関係性とは独立した契約として扱う。
- 既存の仕事AIを流用するため、雇用中は内部的に仕事指示可能状態へ移行する。
- 日給は毎日再計算し、スキル成長と職能Lv上昇を反映する。
- 当日分の給料が支払われている間は忠誠心を最低75に保つ。
- 未払いが発生した時点で作業を停止する。停止中は未払い額を際限なく積み上げない。

### 日給計算
```text
dailyWage =
  max(
    4,
    round(
      4
      + 職能Lv × 1.5
      + 上位2スキル合計 × 1.25
      + 役割補正
    )
  )
```

役割補正:
- Guard: +2G
- Gatherer: +1G
- Family: +1G
- その他: +0G

## FW-2026-10-05-001 — 室内家事AI・清潔度・洗濯・条件比較

実装系列: Frontier V34  
対象: `frontier-world/index.html`  
ゲーム実装コミット: `f99c55e7eb34d859efbdf9e600642b031b41b630`

### 原因
- V19/V24系のNPC家事処理が、家の入口へ到達した時点で屋外座標のまま「料理」「洗濯」「掃除」等を進行させていた。
- V20系の室内同伴処理はプレイヤーの退室時に同伴NPCを屋外へ戻すため、独立して室内家事を続ける住民状態が存在しなかった。
- 自動行動NPCの標準移動速度が約0.92、操作キャラの自動移動が約3.15で大きな差があった。
- 数値ガンビット条件は条件タイプ自体に「以下/未満/以上」が固定され、任意の比較演算子を選択できなかった。

### V34の対策
- `npc.household34` を室内家事の実行状態として追加し、NPCを `inside20` と連携して屋内住民として保持。
- プレイヤーが同じ建物へ入った時だけ室内描画へ同期し、プレイヤー退室時にも作業中NPCは室内へ残す。
- 直接依頼 `homeCraft`、予定表の睡眠/家事/風呂/洗濯/掃除/料理/トイレ/食事、自動行動の料理/風呂/洗濯/掃除を室内タスクへ統合。
- 家具別 `cleanliness34` と家全体平均清潔度を追加。
- 自動掃除は最も汚れた設備を選択し、対象位置へ移動して回復。
- 洗濯は水1を消費する多段工程へ変更。
- `fw17NpcMove` の自動移動速度を 3.05 へ統一。
- 数値条件へ `op` を追加し、`< / ≤ / = / ≥ / > / ≠` を共通比較関数で判定。
- 旧条件は型名から既定の演算子を補完して互換性を維持。

## FW-2026-10-05-002 — 室内家族停止・会話即終了

実装系列: Frontier V34.1  
対象: `frontier-world/index.html`  
ゲーム実装コミット: `51e8db0f38118857f30fd711f5eeb27394df5aa8`

### 症状
- 家族が室内で動かなくなる。
- 室内で隣にいる家族へ話しかけても「離れたので会話を終了した。」となる。

### 原因
1. V34の家事状態 `household34` で `command === 'homeWait'` を予定表より先に判定していたため、結婚/同居時に設定された受動的な `homeWait` が個人予定表を上書きし続けた。
2. 基本更新ループの会話距離判定が `speaker.x/y` と `player.x/y` の屋外座標を使用していた。室内表示は `followers20` / `household34.x/y` の室内座標なので、見た目上は隣でも距離超過と誤判定した。
3. 室内表示中のNPCへ、屋外用の自発会話接近処理が割り込む可能性があった。

### 修正
- 会話距離を `fw35DialogDistance()` 経由へ変更し、同じ室内では実際の室内座標を使用。
- 個人予定表を受動的な `homeWait` より優先。
- `leisure` を室内予定タスクへ追加。
- 余暇/待機時は複数の室内地点を順番に歩く。
- 室内の会話ボタンは実際に近い室内NPCを優先。
- 室内表示中のNPCには屋外の自発接近処理を適用しない。
- 既にV34で待機固定になっているランタイム状態も毎フレーム補修する。

### 静的確認済み
- 全インラインJavaScriptの構文確認。
- `fw35DialogDistance(state.dialog.speaker)` が基本会話終了判定に使用されている。
- `FW34_INDOOR_SCHEDULE.add('leisure')` を確認。
- `fw34NpcTaskStart` で予定表判定が受動的 `homeWait` より先。
- 余暇/待機の移動先が循環することを確認。
- V33商業/V34家事の主要コードが残っていることを確認。

### 手動プレイ確認項目
1. 家の中でMioの隣から会話し、会話ウィンドウが即終了しない。
2. 会話中に室内で3マス以上離れると正常に会話が終了する。
3. 18:00〜21:00の標準予定表「余暇」でMioが室内を歩く。
4. 予定表が家事/掃除/洗濯/睡眠へ切り替わったら、その行動位置へ移動する。
5. プレイヤーが退室しても実行中の家事は継続する。
6. 再入室後も家族が正しい室内位置に表示される。
7. セーブ→ロード後も待機固定が再発しない。

### 現時点の確認範囲
