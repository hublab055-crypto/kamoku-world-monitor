# Frontier World — モンスター四方向 / 初期遭遇案（2026-10-14）

## 基本の3種類
- 盗賊（重み1 / 10%）：人型。短剣・警戒・追跡・逃走。単体出現を基本にする。
- スライム（重み6 / 60%）：弱い敵。弾力歩行・体当たり・消滅。最初の遭遇に適する。
- ゴブリン（重み3 / 30%）：中程度の敵。棍棒攻撃。将来的に集団行動を追加。

## 四方向 / アニメーション
- 向きは正面・左・右・背面。
- 待機・歩行・追跡・攻撃・被弾・戦闘不能の6動作。
- 書き出し目標は4方向×8コマ / 128px×128px / 透過PNG / 1024×512px。
- 独立Canvas描画の仮アートを用意。本編の演出/戦闘ステートと接続するときは既存キャラ戦闘リグとの調整が必要。

## 遭遇率の扱い
- 初期エリアは「盗賊1:スライム6:ゴブリン3」。重み付き独立抽選（盗賊10%、スライム60%、ゴブリン30%）。
- 10体出現時に厳密に1:6:3に固定するわけではない。
- 敵を1フレームごとに抽選しない。移動距離/エリアのスポーンイベント単位で判定する想定。
- データ定義は `frontier-world/data/monsters.json`。数値HPは仮値。
- **本編のエンカウント・戦闘・セーブにはまだ未接続。** 表示プレビューと設定値の段階。
