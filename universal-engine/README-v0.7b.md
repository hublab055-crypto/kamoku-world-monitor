# Universal Engine v0.7b — 衣装・表情と旧版共存

**v0.7b実験版**では以下を追加:
- 衣装10プリセット（開拓者・斥候・職人・農民・商人・司祭・衛兵・狩人・旅人・村人）
- 既存の3種類の人物素体は維持。衣装は素体と独立して変更できる
- 髪型4種類、帽子4種類、マント3種類、鞄3種類、上着/ズボン/靴/髪のRGB染色
- 7表情（平常/喜び/悲しみ/怒り/不安/驚き/疲労）、視線の左右操作、自動まばたき
- 表情用の3D目・眉・口・まぶたメッシュを60関節の顔・顎ピボットへ配置
- 表情/衣装の設定をセーブで永続化
- 旧v0.7aとv0.6の保存データを**読み取り専用**でインポート

ローカル保存キー:
- v0.6 = `universal-engine:explorer:v1`
- v0.7a = `universal-engine:explorer:v0.7a`
- v0.7b = `universal-engine:explorer:v0.7b`

各保存キーは異なり、旧版側のゲームは保存時点の別実行コードを読み込みます。ただし同じブラウザでサイトデータを消すと各ローカル保存は消えるため、セーブ自体のクラウドバックアップではありません。

モデルはオリジナルの低ポリゴン剛体セグメントを着色・増補したものです。衣服の物理シミュレーション、頂点の連続スキニング、NPC自律感情、話しかけて変わる人間関係はまだ未実装。カメラ6モード、遠景、屋内/村はv0.7c以降の計画。

詳細: [v0.7設計](../design/v0.7/)。
