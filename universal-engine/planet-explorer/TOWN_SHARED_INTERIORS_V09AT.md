# Universal Engine v0.9at — 街の一般建物を地表と共通3D空間に統合

## 目的・依存
PR #68で実現した音楽劇場・音楽教室の地表と同一のWebGLカメラ・深度バッファ・惑星原点で描画する方式を、街の一般建物へ段階的に適用する。
依存：#60 → #61 → #62 → #64 → #65 → #66 → #67 → #68 → このPR。

## 対応建物
- 民家（cabin）：ベッド、机、椅子、棚
- 宿屋・集会所（lodge）：カウンター、テーブル、椅子。既存の宿屋音楽・会話・販売は維持。
- 工房（workshop）：作業台と棚
- 穀物倉庫（granary）：積み上げた袋・木箱
- 厩舎（stable）：飼料槽・区画
- 納屋（barn）：物資棚・区画

**既存の建物ID `village-N` とレイアウトは変更しない。** 列車、駅、船室、牢屋、オーナー建築、井戸、見張り台、屋外市場などの内部処理は今回の変更対象外。

## 新規モジュール

### `town-shared-world.mjs`
- 建物種別ごとに既存外観と一致する矩形フットプリントを定義。
- `sharedRoom`、`sharedDoor`、`sharedDoorNear`、`sharedExteriorStep`、`sharedWalkStep`を提供。
- 扉の前約2.5m以内で開閉可能。開いた正面扉の境界を徒歩で横断したときにだけ室内へ移る。
- 閉扉・側面・背面から建物外壁を横断する移動は阻止。室内でも壁と主要家具への簡易衝突判定を追加。
- 町の建物配置は `TownLife._hallSites` という既存の使い捨てキャッシュに一度格納し、毎XRフレームの再構築を避ける。
- `angle`情報は現状の街の外観が回転を適用していないため、一般建物の座標変換にも回転をかけない。劇場等の回転対応は従来通り。

### `town-shared-geometry.mjs`
- 一般建物6種類専用の室内家具ジオメトリを作成。
- 従来の `townInteriorGeometry()` の壁・床・家具を地表上にそのまま重ねず、地表用の床と家具だけを生成する。

## レンダラー
- `scenery-geometry.mjs`に`sharedTownShellGeometry`と`sharedTownRoofGeometry`を追加。従来の実体のある直方体を、正面に歩ける開口部を備えた壁殻と独立した屋根に分離。
- `render.mjs`は一般建物を従来のまとめ描画メッシュから取り出し、壁殻と屋根を別のGPUメッシュとして描画。
- `drawSharedTownWorld`で、実際の地形パッチ上に床・家具・開閉扉を描く。外から開いた入口越しに家具を表示できる。
- プレイヤーが内部にいるときはその建物の屋根だけを非表示にし、TPV/RTSでの視界を確保。
- 家具/開閉扉の個別描画はプレイヤーから180m以内に限定して、遠距離の不必要なドローコールを抑える。
- 全体は既存の `ground()` 描画、地表アバター、WebXRヘッドセットの同じカメラ・深度バッファを使用する。住宅/宿屋に入ったときだけ旧 `renderTownInterior`へ切り替える処理は無効化。

## 移動とゲーム状態
- `TownLife.toggleHallDoor()`と`hallStep()`を建物6種類へ拡張し、既存の「街の生活」UIから扉の開閉と入室が可能。
- 徒歩で扉を通過すると、横断時の局所座標を `hallLocalPoint` で引き継ぎ、`syncHallActorWorld`で本当の `ExplorerController.x/z/lat/lon/yaw`と一致させる。
- 室内の家具・壁にぶつかっても外の地表へ突き抜けない。退出方法は開扉からの徒歩退出と街の生活パネルの「外へ出る」。どちらも建物の屋外入口付近に戻る。
- 惑星 `origin`、NPC/建物ID、鉄道や船の独立室内、会話/売買、既存セーブ形式を維持。
- 扉の開閉状態と室内の一時姿勢は従来と同様に非永続セッション状態。再起動後は街の屋外から再開。

- 実際のNode.jsテストランナー、WebGLブラウザ統合、Safari・Quest 3/3S実機のフレームレート・表示/物理動線は未検証。

## 次段階・既知の制限
- この段階の建物は街の共通の配置物であり、ユーザー所有権、賃貸、鍵、窃盗、NPCの私生活動線、火災などは未実装。
- シンプルなAABB（軸平行矩形）で歩行判定。扉の実物理、手による押し引き、建物のyawを含むフル衝突、家具ごとの詳細ナビゲーションには未対応。
- 一般建物の共有描画は6種類だけ。鉄道車両・船内・宇宙船・地下施設・牢屋には専用の描画が残る。
- 丘や斜面上での地面と屋内床の完全な一致、地形パッチの整地・基礎工事は要実機調整。
