# Universal Engine 音楽文化・職業・NPC公演 v0.9an

## 依存と開発順
PR #60（音楽プレイヤー・作曲） → #61（3D楽器・VR演奏） → #62（クラフト・Asset楽器） → 本PRの順に統合。
既存の惑星移動、都市計画、鉄道、治安、貨幣、所有権の保存構造は変更せず、独立した `MusicCulture` と `v0_9an` を追加した。

## 機能
- 既存の都市・村に以下の**文化活動ポイント**を設置。座標は `settlementLayout()` と同じ地表局所メートルで固定し、既存の景観原点（`s.origin`）と描画中心（`cx/cz`）に合わせて描画する。
  - 宿場の演奏会：宿屋近く（19:00・21:00）。観客数は街の住民数から決定。入場5G。
  - 街の広場・音楽劇場：中央広場（14:00・18:00）。入場8G。
  - 音楽教室：街の道路・広場付近（9:00〜17:00）。授業料12G。
- NPC演奏者はその街に存在する`resident-N`から決定。日中・夜の公演時間に、既存レンダラーで3Dステージ、演奏者、観客の簡易モデルが表示される。
- NPC演奏曲は本実装で作成した**独自の短いメロディー**を既存作曲エンジンの`renderScoreWav()`で出力して再生。音楽パネルから「▶ NPC演奏を聴く」、または近くで公演を始めると一度自動再生を試みる。ブラウザの自動再生制限がある場合はボタンを押す。
- チケット購入は`TownLife.coins`を減算し、会場予算へ加算。一公演ごとに1回のみ購入可。
- プレイヤーはクラフト済み楽器を所持している場合、出演料を受け取り、演奏技能・評判を獲得できる。出演料は会場予算の範囲内で支払う。公演ごとの重複受給不可。
- 公演に出演すると、編集中の自作曲の演奏が始まる。自作曲の保存・レコードへの登録は既存Music Studioを使用。
- 音楽授業は1つの街で1惑星日1回まで。授業料12Gを会場予算へ加算し、演奏技能+5。
- NPCは開演日に会場予算から一度だけ給与が支払われ、演奏家の累計収入と職業経験が蓄積。予算を超える支払いを行わない。
- 曲／楽器の共有・マルチプレイヤー市場への送信は本段階では対象外。
- 保存：`MusicCulture.snapshot()`は技能・評判・会場予算・参加済公演・出演済公演・授業・NPC給与・演奏家の累計収入・経験・ログを格納。ゲームセーブスロットの`v0_9an`及び端末ローカルに対応。

## 操作
1. すでに存在する街・村（王都、塔の街、港町、山村など）へ訪問。
2. 画面の「🎭 音楽文化」またはクイックメニュー「🎭 街の音楽」を開く。
3. 会場の住所（街の東西/南北メートル）を確認し、近く（11m以内）へ歩いて向かう。
4. 公演時間内なら「NPC演奏を聴く」「鑑賞」「自作曲を披露」「出演して報酬を得る」を操作。
5. 教室では営業時間内に授業を受ける。NPC職業の累計収入・経験を観察できる。

## 第1段階の制限
- ステージ・簡易NPC・観客は静的な外観に近く、楽器の鍵盤を指で押す骨格アニメーション、演奏家の移動経路や座席、実際の会場建物への入室は未実装。既存の街の建築を破壊・移動する変更は行わない。
- 自動公演の音源は会場ごとのオリジナル短曲であり、NPCがユーザー作曲ライブラリから曲を学習・アレンジする機能ではない。
- プレイヤー出演判定はゲーム内クラフト済み楽器の所持・設置と公演時間により行う簡易アクション。演奏精度評価や楽器操作を完了する必要性は次段階。
- 会場は独立の仮想会計で初期資金120G。既存`TownLife.coins`を貨幣単位とし、全ての収支は会場会計から資金の受け渡しを行う。自治体財政や営利企業の本格帳簿との相互送金は次段階。
- 音声は既存のHTML Audioプレイヤーによる短いオリジナル楽曲再生。壁による遮音、HRTF位置追従、遠距離NPCの継続再生、演奏テンポ同期は未対応。
- 本段階の文化会場はTerraの既存村・都市のみ。宇宙船内や新規惑星の自作街への配置、建物所有者の自由経営は次段階。
- SaveSlot`v0_9an`は過去保存を壊さないオプションスキーマ。旧保存は`MusicCulture`初期状態から開始。
- 現段階ではWebGL2・Quest 3/3Sの手動実機確認は未実施。
