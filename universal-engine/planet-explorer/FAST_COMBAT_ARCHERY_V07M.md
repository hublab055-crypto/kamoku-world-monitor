# Universal Engine v0.7m — 高速武器・段階式弓アニメーション

更新：2026-10-16

## 操作方法
- 地上で ⚙ 装備編集 → 人物 → 「⚔️ 攻撃モーション」を選択する。剣は「縦振り」「横薙ぎ」「突き」「連続3撃」、斧は「縦振り」「横薙ぎ」「連続2撃」。
- 装備中の左右の手ボタン、クイック5枠の「使う」、道具メニューの剣/斧ボタンに適用。選択は人物ごとに保存。
- 以前のデータには「縦振り」を適用して保存形式を維持。斧の「突き」は自動的に縦振りへフォールバックする。

## 速度
- 剣の一撃：0.95秒 → 0.58秒。斧の一撃：1.45秒 → 0.78秒。
- 剣3連撃は1.42秒、斧2連撃は1.38秒。モーションの遅れ（滑らか補間）も高速攻撃時は低減。
- NPCも同じ時間と攻撃スタイルを使用。クイックアクションの弓は実際に装備された側の手を使用する。

## 弓（1.62秒）
1. 0–22%：弓を肩の前へ持ち上げる。
2. 22–40%：反対の手で矢を持って弓の弦へつがえる。つがえる前には矢を表示しない。
3. 40–71%：弦と矢を頬へ向けて後方へ引き、V字の弦に張力をかける。
4. 71–76%：狙いを保持。
5. 76–82%：指を離して弦を戻す。
6. 78–100%：矢が前方へ飛翔し、手を戻す。

矢の残数とクラフト資源はv0.7lと互換。射撃開始に成功したときだけ1本消費する。
弓の射撃中は空いていない方の手から剣や斧の表示を一時的に外し、矢をつがえるための手を空ける。

## GLBの対応と限界
- 名前付きの waist / rightShoulder / leftShoulder / rightElbow / leftElbow があるGLBでは新しいアニメーションを関節へ適用。右手・左手の向きは左右反転。
- 骨名や骨軸が異なるユーザー持込GLBは固有クリップを使用し、完全一致しない場合がある。
- 敵への弾道命中判定、威力、矢の回収、近接の実ダメージは未実装。今回の追加はプレイヤーとNPCの装備操作・見た目のモーション。
- JavaScript構文および数値ロジックを検証。iPhone/Safariでの最終的な3D外観、標準GLBの実機リターゲットは未検証。
