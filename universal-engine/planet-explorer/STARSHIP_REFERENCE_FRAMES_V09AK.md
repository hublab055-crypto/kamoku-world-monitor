# v0.9ak：地域原点を保護する宇宙船座標基盤

更新日：2026年11月1日

## 今回の範囲

地表→船内→別天体→地表の次段階設計に対する、最初の実装です。
既存の宇宙船状態機械、WebGL2描画、シナリオ、新規冒険開始、セーブ形式を維持します。

実際のゲーム処理で変わる点：

- 下船時、船内の位置を現在の地域座標へ戻します。`controller.setLanding()`で地域のoriginを船体位置に置き換えず、仲間の再配置も下船だけでは実行しません。
- 別天体へ着陸するときも、ロードした地域のoriginを保持し、その地域内のx/zで着陸地点を表します。初訪問天体の既存初期化は維持します。
- 船の地表位置と乗船距離を球面局所変換で計算します。±180度の経度境界を挟んだ近くの船を、惑星一周分離れた船として扱いません。
- 再訪問先の着陸候補は、旧Explorer v1の`origin + x/z`から求めます。この形式には通常lat/lonが保存されないため、初期の谷へ候補探索が戻る問題を防ぎます。
- 到着プレビューには目的天体と一致する訪問済み記録だけを受け入れます。

木・資源の生成セルID、NPC・建物のローカル位置、駅・鉄道の経路、シナリオ・世代の保存内容は書き換えません。船内歩行や座席・ハッチの安全条件は既存処理を使用します。

## 新しいCPU座標サービス

`reference-frames.mjs`は副作用のないNumber精度の変換を提供します。

- `rigidFrame`：正規直交・右手系の基底、位置、並進速度、角速度を検証して固定。
- `toParent` / `fromParent`：位置・速度を相互変換。回転frameの`omega × offset`を含む。
- `bodyFrame`：既存の天体軌道・自転・軸傾斜と同じ規則。AUを一度だけmに変換。
- `orbitalVelocityMps`：惑星と衛星の軌道式を解析微分し、衛星には親天体の速度も含める。
- `relativePoint`：絶対位置をFloat32化する前に共通親frame内の原点差を取る。AU級の中心とmm級の相対位置を別々に扱える。
- `tangentFrame`：既存のX東・Y上・Z北の基底。
- `surfaceLocalOffset`：日付変更線、高緯度、近距離に対応する球面局所写像。対蹠点は別地域が必要として拒否。

星系・船体の剛体変換は今後の描画・物理統合の基盤です。この版では飛行中の見た目やカメラをこの変換へ一括移行していません。実行経路への接続は、地表船の距離判定、着陸・下船位置の変換です。

`region-anchor.mjs`には固定origin、seed、生成器version、content revisionを持つ不変の`regionAnchor`と`LegacyRegionAdapter`を追加します。旧生成器のseedや地理座標を維持し、天体・地域を含むEntity IDを作れます。これは地域ストリーミング向けのAPIであり、この版で既存セーブへ新しい地域レジストリを保存することはしません。

## 保存互換とエラー

SurfaceStarship schemaVersion 1、ShipJourney schemaVersion 2、Explorer v1の形式はそのままです。元のsnapshotを変更せずに位置を解決し、ロード後の地域原点も維持します。

無効座標・非有限値・反転した座標基底を拒否します。地表船の局所距離が定義できない場合はnullを返し、乗船させません。別惑星の保存記録を到着プレビューへ渡した場合は明示的に失敗します。天体移動の既存の復帰処理は維持します。

## 検証

新規 `tests/starship-reference-frames.test.mjs` で次を検証します。

1. Terra・Selene・Cinder・Nixの自転と軸傾斜が既存Planetの法線と一致。
2. 天体中心のAU/m変換、親天体を含む衛星速度、回転frame間の位置・速度往復。
3. AU級中心でのmm級描画相対差。
4. 日付変更線・高緯度・近距離の球面変換、対蹠点と不正入力の拒否。
5. 元のoriginと旧セーブを変更しない下船・着陸位置の計画。
6. 地表出入りを100回計画しても、同じ生成条件の木・街のNPC・建物・鉄道路線位置が不変。
7. 実際のTerrainで再訪問時に保存された遠方地点の近くへ着陸候補を選び、訪問済み記録を変更しないこと。

上記はNodeでのモデル検証です。ブラウザ画面の継ぎ目、当たり判定全体、Safari・Questの実機操作を確認したことにはなりません。

実行結果（Node v24.22.1）：

- 変更前の `node --test --test-reporter=tap tests/*.test.mjs`：676件中628件成功、48件失敗。
- 変更後の同コマンド：694件中646件成功、48件失敗。失敗テスト名の集合は変更前と一致し、新規失敗は0件。
- 新規18件と既存宇宙船テスト14件の個別実行：32件すべて成功。
- 変更したJavaScriptの構文検査、差分の空白検査を通過。
- ローカルのブラウザ起動試験はChromium実行ファイルが未配置のため実行できず、WebGL起動・実画面は未確認。
