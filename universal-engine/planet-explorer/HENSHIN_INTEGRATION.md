# 変身工房の本体統合（2026-11-21）

## 遊び方

通常メニュー／操作メニューの「変身工房」、またはタブレットの設定→「変身工房」から開きます。

1. ゼロワン・ジオウ・ゴースト・鎧武を選択。
2. 「ベルトを装備」→「変身の次の操作」を4回。変身中のみ試作ヒーローモデルを表示します。「変身解除」で元のアバターに戻ります。
3. 「VRで遊ぶ」は既存のゲームVRセッションへ接続。「MRで遊ぶ」は部屋を背景にした専用MR変身モードへ接続します。
4. 「工作・音・モーション」で色・サイズ・追加パーツ・関節・音源を編集し、親パネルの「ゲームへ反映」を押します。
5. 「作品を本体に保存」で次回にも引き継げます。記録音声は同じサイトのIndexedDBを共有するため、工房で割り当てた音を本体で再生できます。

## ヘッドセット内の操作

- 右腰の前に置いたアイテムに手を近づけ、左右どちらかのグリップで把持。ベルトに近づけて離すと装填。
- ベルト付近のトリガーで簡易操作を進め、変身後は必殺技エフェクトと音を再生。
- コントローラーで正面左のパネルを指し、トリガーで操作。STEP=変身操作、HIT=必殺技、RESET=解除、NEXT=ライダー切替、POSE=関節編集、REC=記録開始／停止、PLAY=再生、WAIST=左手の高さへベルト位置を調整、EXIT=XR終了。
- POSEモードでは正面のモデルに表示する関節球を左右グリップでつかんで移動。RECで編集結果を記録できます。POSE以外のRECは頭と両手から推定した腕を記録します。
- VR終了後「工房の作品へ現在の動きを送る」で、本体で記録したモーションを工作画面へ送り、JSON出力できます。既存のVRモーションアクターは従来通り別の記録機能として利用できます。

## 本体への接続

- `app.mjs` に1つの `HenshinRuntime` を作り、初期化／ワールド変更後のレンダラーでも共有。
- `render.mjs` の既存WebGL2描画経路でベルト、ヒーロー試作モデル、アイテム、エフェクトを描画。変身解除後は保存されたV10／従来モデルへ復帰し、GLBや衣装設定を変更しません。
- 地表・船内のプレイヤー表示に接続。VRの一人称では頭を隠した身体と追跡した手、正面には確認用のモデルを表示。通常の身体との二重表示を防止します。
- `xr-ui.mjs` で新鮮な実測姿勢を毎フレーム渡します。アイテム／ベルト／パネル／関節の実際のヒット時だけ既存入力を消費し、同じ操作で剣や弓が発動するのを防ぎます。
- MR変身では透明背景で部屋を維持し、模型用のステージ変換を使わず実寸の室内座標に描画。床追跡を必須にし、VR/MR切替時は既存のXR終了手順を使います。
- 工作画面は同じサイトに `henshin-studio/` として同梱。iframe内のVR/MR開始ボタンは無効化し、本体の1セッションだけを使います。通信は親ウィンドウとoriginを検証。
- 作品保存は専用キー `universal-engine:henshin:project:v1`。既存のゲームセーブ形式を変更しません。初回のベルト装備は任意です。

## 制限

- 各作品を識別する色や簡単な形を持つ独自の試作モデルです。公式GLB・劇中音声・劇中映像は含みません。ベルトの可動機構、劇中スーツの精密再現は未実装です。
- 必殺技は演出と音です。既存の敵に与えるダメージ、対人戦、戦闘バランスには接続していません。
- 腰・足は実測しません。足は編集したポーズか歩行用の簡易動作。MRの実物による遮蔽や衝突、空間アンカーの永続化は未実装です。
- マイク録音は工作画面から開始し、端末内へ保存。音声をサーバーへ送信しません。別端末への移動時はJSONと音声を別途書き出し、移動先で音を再割当してください。
- 元の別サイト（henshin-workshop.chatgpt.site）に保存した音源は、保存先originが異なるため共有されません。音声ファイルを本体側工房に追加してください。
