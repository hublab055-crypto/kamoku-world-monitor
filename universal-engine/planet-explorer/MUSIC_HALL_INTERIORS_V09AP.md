# Universal Engine v0.9ap — 音楽劇場・教室の室内とQuest指先演奏

## 目的と依存
- 依存：PR #60 → #61 → #62 → #64 → #65 → 本PR。
- 既存 `TownLife` / `renderTownInterior` / 住人ID / 音楽文化経済 / 楽団の契約を維持したまま、文化施設の外観、入退室、歩行、客席、教室でのライブと学習を接続する。
- 新規施設はすべて既存の都市/村の `settlementLayout` 最後に追加するので、従来の `village-N` に関連する建物IDは変化しない。
- 新規の惑星グローバル位置に依存するセーブ要素は追加しない。音楽施設の屋外座標は `settlementLayout` の局所メートルに固定し、既存の観測原点/地形描画変換をそのまま使う。

## 変更の概要
### 1. 街の専用建物
- `music-hall.mjs`：劇場/音楽学校の決定論的な敷地、室内の歩行範囲、座席のレイアウトを定義。
- 各都市に音楽劇場 `(x=0,z=48)` と音楽教室 `(x=0,z=-48)` を追加。既存の住宅・市場などを削除したり移動したりしない。
- `scenery-geometry.mjs`：劇場と学校を区別した専用外観・入口マーカーを生成。
- `MusicCulture.venue()`：文化施設の公演位置を新しい建物位置に合わせる。従来の街の中央に浮遊する舞台と建物が重ならないよう、専用施設のステージ/演奏者は室内だけに描画する。

### 2. 劇場の室内
- `music-hall-geometry.mjs`：外壁を手前側でカットした劇場、緞帳、舞台袖、ステージ灯、座席4列16席をローポリゴンの静的ジオメトリとして実装。
- `TownLife.enter()`：従来の建物入室と同じ `village-N` IDから入れる。初期位置は入口近くの `(x=0,z=8.6)`。
- `TownLife.walk()`：劇場だけ拡張歩行範囲 x ±8.3m、z −10.2〜10.2m を採用。通常家屋の小部屋歩行範囲は変更しない。
- 客席の近く（1.3m以内）で `sitMusicSeat()`、`standMusicSeat()`。着席したら `TownLife.walk` が移動を止め、立ち上がってから移動再開。
- `TownInteractionUI` で「💺 近くの椅子に座る」「🧍 席から立ち上がる」を操作。
- 音楽文化パネルからも「🚪 建物に入る」「🚪 会場を出る」「💺 客席へ座る」を使える。
- 惑星の公演時間で舞台に演奏家/契約中の楽団員、客席にNPC観客を表示。プレイヤーが座っている席はNPCの描画対象から除外する。
- 観客の拍手と楽団の演奏姿勢は既存の事前生成メッシュ4フレームを利用。室内でも`performance.now()`に基づきポーズ更新できるよう修正（以前は水面更新の時計に依存していた）。

### 3. 音楽教室
- 学校の外観と教室内の黒板/鍵盤/机・椅子（3列9席）を追加。
- 教室は入室/歩行/着席可能。室内講師を学校の営業時間中に表示。楽団の有償出演者は学校に自動移動しない。
- 既存の `MusicCulture.lesson()` で授業料と技能の処理を行う。講師へ物理的に話しかける専用ダイアログは今後の段階。

### 4. Meta Quest 手指追跡の選択対応
- `xr-ui.mjs` のWebXRフレームから `XRInputSource.hand` の `index-finger-tip` と `XRFrame.getJointPose` を、利用可能な場合だけ読み取る。
- 先端の座標を `music-ui.mjs` に転送し、`musicStageHandHit()` の接触オフセットを0に設定（±0.065m判定）。
- 未対応・一時的な追跡喪失時は、従来の握り/コントローラー位置の推定指先（前方約0.06m、±0.12m判定）へフォールバック。
- `XRHand` APIが無いブラウザでは従来の音楽演奏や弓・剣・装備操作を維持。手追跡の開始やWebXRのoptionalFeaturesの追加要求はしていない。

## 保存と安全性
- 客席での姿勢と屋内状態は従来の `TownLife.inside` の一時状態。再ロードは今までと同様に屋外から再開。特別な永続セーブ形式の変更はなし。
- 既存のNPC会話、給与、音楽著作、住宅、鉄道、惑星、宇宙船の保存形式を変更しない。
- 地表上で追加された新施設は決定論的な景観に含まれ、通常のセーブ対象になる建築Assetとは別物。
- 通常の市場や宿屋、留置所などの既存室内は同じモデル/歩行範囲を使う。VR勾留歩行・鉄格子操作も変更しない。
