# v0.7x 惑星の任意地点を選択して降下

## 操作
1. 「↑ 宇宙へ戻る」で地球儀を表示。惑星をドラッグして見える面を変更、ピンチやホイールで拡大縮小。
2. 惑星の表面を**1回タップ**すると、画面下に緯度・経度、地形種別、陸上なら標高を表示。マーカーは球面上に表示する。
3. 「↓ この地点へ降下」または上部の「↓ 地表へ降下」でその場所へ移動。**ダブルタップ**は選択して直接降下。
4. 地表メッシュへ自動的に切り替わり、従来のTPV / RTS / 自動行動を継続できる。降下中のカメラ倍率変更も可。
5. 「✕」で取り消し。選択だけではアバターは移動しない。惑星外をタップしても地理座標は作らない。

## 数学・整合性
- `orbit-landing.mjs` はレンダラーの実際の view-projection 行列の逆行列で近点・遠点をアンプロジェクト。
- 球面と光線の交点を前面優先で求め、球面法線から緯度・経度へ変換。
- 描画時の自転経度オフセットを差し引いてゲーム世界の同一座標を得る。経度は ±180° で折り返す。
- 既存の `controller.setLanding` → `squad.repositionAfterLanding` → `controller.targetAltitude(2.5)` を再利用。降下は対数高度補間。
- 選択した座標は保留中のUIデータで、確定までプレイヤー位置・保存データを変更しない。

## 既知の制約
- 惑星全域の緯度・経度を選べるが、海面には水泳・船・潜水・飛行がまだない。海上で歩行は衝突判定により制限される。
- 高山、河川、急斜面では従来の歩行制限が有効。
- 降下中の表示切替は既存の高高度球体・地上メッシュ二段階方式で、連続地形LODや大気突入エフェクトは将来課題。
- ローカルの建築物・活動地点の惑星全域永続化は別タスク。別地域に切り替えた際の地域別ワールド管理は未実装。
- 頂点モデル上の陸海境界は見た目が粗いため、選択時の地形分類はモデルより詳細な `terrainSurface()` の結果を優先する。
