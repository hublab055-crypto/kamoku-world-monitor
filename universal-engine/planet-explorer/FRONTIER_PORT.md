# Frontier World → Universal Engine 第1段階（2026-10-16）

## 今回移植した実装

- 3D惑星上で各アバター（開拓者・斥候・職人）個別のスタミナ、持ち物重量、インベントリ、行動半径・中心を保持。
- 既存の8スロットIF/THENへ、スタミナ30%以下→100%まで家で休息、持ち物18kg以上→チェストへ全収納、半径内の資源を全回収、を追加。
- 優先順位を上下入れ替えられる。アバター選択とON/OFFは従来のRTS UIを使用。
- 着陸地点周囲に有限資源を生成し3Dモデルで表示。採集で資源数を減らし、袋へ収納。
- 木材・石・繊維は従来のActions.resources、食材・水はLifestyle.inventoryへ納品し、家事クラフトの材料に接続。
- 建築済みの小屋がある時は小屋へ、ない場合は着陸地点の仮拠点へ帰還。
- SquadEngineスナップショット内にFrontierデータを保存。旧セーブは新項目なしでも起動（新項目にデフォルト値を適用）。

## 引き続き未移植

フロンティアワールド全体の住民会話、家族・家系、職業・雇用・給与、村経済、紙と出版・印税、司祭・学校、農林畜産物・物流、戦闘・外交・物語は段階2以降。
