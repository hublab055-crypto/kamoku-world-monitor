# Universal Engine Music Studio v0.9ak — 機能仕様と展開計画

## 目的
「音楽を聴く」だけでなく、冒険中に曲を制作してレコード作品として所有し、
音楽プレイヤーで流しながら探索できる基盤を追加する。
既存のメディア・文化作品、惑星座標、鉄道、XRコントローラー、既存セーブスロットの仕様は変更しない。

## 第一段階：このPRで追加
- 🎧 **音楽プレイヤー**: メディア台帳に保存済みのレコードを一覧表示し、再生・停止・ループが可能。画面を閉じても再生継続。
- 🎹 **キーボード**: 画面上のC4〜C5の13鍵をタッチ／マウスで演奏。PCではA〜L周辺の9キーで音を出せる。
- 🎸 **ギター**: 標準チューニングの6弦、開放弦〜7フレットをタップして演奏。現段階ではシンセサイザーによるギター風音色。
- 🥁 **ドラム**: キック、スネア、ハイハット、クラップの4パッド。
- 🎼 **作曲**: キーボード、ギター、ベース、ドラムの4トラック、2小節／32ステップ、BPM40〜240。音程選択後にステップをタップして配置・削除。
- ● **演奏記録**: 録音開始後の押鍵・離鍵を16分音符で量子化して楽譜へ記録（端末マイクの録音ではない）。録音範囲は2小節、最大音符数512。
- 💾 **楽譜保存**: 曲名を付けて最大30曲、ブラウザのlocalStorageに保存。保存ボタン操作による保存。
- 💿 **レコード化**: 作曲内容をオフラインでPCM WAVにレンダリングし、既存MediaLibraryのrecord種別・IndexedDBへ登録。ギフト・展示・既存メディアプレビューの対象にできる。
- ⬇ **WAV書出**: WAVファイルのダウンロード。手持ちの対応音声ファイルをメディア台帳に登録して音楽プレイヤーで再生。
- アプリUIへの起動ボタンを既存のメディア・文化作品の隣に追加。既存メディアの保存形式やセーブデータへの変更なし。

## 使用方法
1. ゲームの「🎵 音楽スタジオ」を開く。
2. 鍵盤を弾くか、ギター／ドラムを展開して演奏。
3. ステップをクリックして音符を置く。または「● 演奏を録音」で記録。
4. 曲名とBPMを設定して「💾 楽譜を保存」。再生ボタンで確認。
5. 「💿 レコード作品に登録」で既存メディア作品を作る。作品を自分の音楽プレイヤーで再生可能。
6. 曲を外部ファイルとして使いたい場合「⬇ WAV保存」。ゲーム内BGMとして聴きたい場合はレコードを再生し画面を閉じる。

## 技術設計
- **music-core.mjs**: ブラウザAPIと分離した楽譜の正規化／検証／PCM合成。
- **music-ui.mjs / music-ui.css**: 軽量DOM UI、Web Audioによるライブ演奏、レコード一覧、楽譜操作。
- **media-ui.mjs**: registerAudioRecord() を追加。音声レコードは従来と同じmedia-library/IndexedDBに保存。
- **index.html / app.mjs**: 音楽スタジオをメディアUIの後に初期化。
- 軽量なコード生成音源を使い、外部音源・新規ライブラリ依存・著作権のあるデモ楽曲を同梱しない。

## 限界と次段階
- 今回は**画面上の2D演奏とレコード作品の連携**。3Dピアノ・ギターのメッシュ、アバターの演奏モーション、VRの手指／グリップによる弦と鍵盤の操作、演奏者の位置に応じた3D音響は次段階。
- 作曲は2小節固定・量子化単位固定。長編曲、楽譜譜面、MIDI入出力、マルチトラックミキサー、楽器音源のサンプル再生、マイク録音、バンドのリアルタイム合奏は次段階。
- ブラウザ保存は**端末ローカル**。音声バイナリはゲームセーブJSONに含めない。セーブスロット間で楽譜は共通。
- 著作権のある市販楽曲等をマルチプレイヤーへ再配信する仕組みは追加しない。プレイヤーが利用権を持つ素材のみ共有対象とする。
- ブラウザが音声の再生／WebAudio開始をユーザー操作まで制限する場合がある。音楽スタジオの操作で再生開始。
