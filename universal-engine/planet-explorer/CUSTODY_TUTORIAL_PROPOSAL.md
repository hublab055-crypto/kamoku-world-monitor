# Universal Engine — 拘置所チュートリアル構想（案・未実装）

2026-10-25 / 対象: planet-explorer、VR（Quest 3S）と通常操作

## 原則
- ゲーム本編の通常開始・既存セーブは一切強制的に留置所スタートにしない。「はじめから」から任意選択の導入シナリオとする。
- 既存の `law.custody`、`railwaySecurity.jailed` は治安／刑事処理であり、チュートリアルは別個の `detentionTutorial` 進行状態とする。
- 物理的に鉄格子を通過できず、看守から刑期・保釈を確認できる。行き詰まりを避け、操作説明・スキップ・やり直し・自動セーブを用意する。
- 移動、会話、食事、飲水、睡眠、積み木・斧・ツルハシの使用は**実際のアバター操作**で習得させ、メニューだけで達成させない。
- VR表示と非VR表示で同じ進行状態／報酬／条件判定を使う。VR側では世界に固定された字幕・照準・選択パネル（両眼3D）を別途実装し、音声の可否に依存しない。

## シーン構成
1. 初日の朝、ベッドで目覚める。眠りから覚める短い演出ののち、自分で立ち上がる。
2. 鉄格子の向こうの看守を訪ねる。「目が覚めたか。お前は誰だ、名前を聞こう」。プレイヤーの名前を入力（入力不能なVRでは後から名前を設定できる初期値あり）。「線路に侵入したため、ここへ拘束した。刑期は三日だ」。
3. 食堂からパンと水を受け取る。手で持ち、食べる／飲む。空腹・スタミナ変化を表示。
4. 指定作業を体験する。工房ではプレート上に積み木10個／日。中庭では斧で木5本／日。採石場ではツルハシで石を割り、規定量を納品。
5. 寝床へ戻り、睡眠でスタミナを回復。所定作業の達成、睡眠、看守への報告で次の日へ進める。
6. 三日目の看守との会話で刑期満了。看守が門を開錠し、出口まで徒歩で進んで解放。新しいゲームとして街・鉄道・世界探索に接続。

## 進行モデル（提案）
```
detentionTutorial = {
  enabled: false,
  phase: 'wake'|'identity'|'meal'|'work'|'sleep'|'report'|'released',
  day: 1,                          // 1..3
  playerName: null,
  quota: { blocks:10, trees:5, stones:0 },
  completed: { blocks:0, trees:0, stones:0 },
  equipmentIssued: false,
  releaseKitIssued: false
}
```
- 日課は最初は一つを選ぶルート制（複数を強制すると長くなるため）。積み木10個・木5本・採石納品は、それぞれ別のチュートリアル行動として使用可能。
- 木や石は毎朝の作業用オブジェクトを配置し、資源採掘後の納品をトランザクション化（重複加算・セーブ読み直しによる二重受領を禁止）。
- 3日の進行は施設内のチュートリアル時計で管理。惑星標準時の変更は確定時のみ反映。既存の逮捕・保釈・服役時間と二重計上しない。
- やさしいモードでは作業ノルマや3日目までの経過を省略可能。VR酔い軽減、会話字幕と物理ボタンを必ず併用する。

## 釈放時に支給するもの
- テント ×1
- ベッドロール ×1
- 10G
- パン ×3（日分）
- 水 ×3（日分）
- 斧 ×1
- ツルハシ ×1

いずれも既存インベントリ形式で実アイテムとして支給する。所持重量が超過する場合は出口の受取箱に移す。報酬は `releaseKitIssued` を先に永続化して重複受領を防ぐ。

## 今回の小規模修正との関係
今回実装したのは、**現在の逮捕・勾留からVRで出るための看守会話と保釈／服役操作**まで。初回名前入力・労働・3日進行・物資支給・扉の開閉・VR 3D字幕・新規開始メニューは、この仕様を起点とする別機能。既存の刑罰は従来の期間・罰金で動作する。

## 受入確認
- 新規通常開始と旧セーブで導入編が勝手に始まらない
- 鉄格子をすり抜けられない／看守へ行ける／VRボタンで会話と釈放が可能
- すべての作業は空振りや納品未完了では進捗しない
- 最中のセーブ・再起動で日数と所持品の二重計上が発生しない
- 解放後は通常の3Dワールド、VR、移動、装備、セーブが継続する
