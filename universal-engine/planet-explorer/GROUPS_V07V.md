# v0.7v — 隊形追従と複数部隊への同時指揮

前版 [GROUPS_V07U.md](./GROUPS_V07U.md) の登録グループを拡張します。

## 隊長基準の隊形追従
- 部隊登録・編集画面に「👣 隊長に隊形追従」を追加。新規部隊では初期ON、既存セーブでは未設定ならOFFとします。
- RTS操作下部の「👣 追従ON/OFF」は選択中の名前付きグループをまとめて切替えます。
- 部隊の先頭メンバーを隊長とし、隊長の現在位置と移動方向（移動中は目的地の方向、それ以外は向き）から横隊・縦隊・楔形・方陣の各オフセットを繰り返し算出します。
- 隊員の目標が0.65m以上変わり、現地点と目的点が1m以上離れたときだけ追従指示を更新して、細かい入力の連発を抑えます。
- 各隊員の地形を検査し、水域・河川・高地（>2800m）の追従目標をスキップします。完全な回り道経路探索や物理衝突回避はまだありません。
- 先頭の隊長は操作可能です。プレイヤーの手動入力、個人に出した目的地指定、明示的な停止指示、資源収集中、作業アニメーションなどを優先します。個人の移動指示で追従が解除された隊員は追従ボタンをONにし直すと復帰します。
- 移動命令（隊列の地面ダブルタップ、登録集合地点への移動、隊形整列）を出すと選択グループの追従制御を再開します。

## 複数グループ同時指揮
- RTS下部に「☑ 複数部隊」パネルを追加。グループ名にチェックを付けて複数同時選択。対象人物は重複を取り除いた和集合で表示。
- 複数部隊の地面ダブルタップ移動は隊ごとに別の着地点を割り当て、各隊内で保存した隊形を使用。今は左右12m間隔（隊数で対称配置）で、人数に応じた動的衝突判定ではありません。
- パネルから「📣 全隊集合」「↔ 全隊整列」「⏹ 全隊停止」を一括操作。
- シンクロ ON で選択アバターへ一斉射撃・対応近接・作業行動を発行（既存の弾数・装備・行動可否を各人物ごとに判定）。
- 同一アバターが複数登録部隊に属する場合は選択順の早い部隊を優先。後続部隊に属する非重複隊員には静的な目的地指示を与えます。全隊停止では重複した人物も1回だけ停止します。

## データ互換性
`v0_7d.squad` の `version:1` のまま `groups` に `follow` と `activeIds` を追加。古い登録部隊の `activeId` から単独選択を復元、旧セーブで `groups` 未定義なら空の登録部隊として起動します。

## テスト
`universal-engine/tests/group-follow-multigroup-v07v.test.mjs` は登録・複数選択・追従ON/OFF・個別命令の優先・重複グループ停止・保存互換を検証します。
`npm test` は `universal-engine` ディレクトリ内で実行します。
