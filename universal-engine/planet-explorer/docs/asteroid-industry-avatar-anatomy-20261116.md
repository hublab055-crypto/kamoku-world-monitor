# Universal Engine — 小惑星採掘／アバター人体構造 試作（2026-11-16）

## 方針

既存の船内・船外視点、XR操作、敵機ロック、従来モデル、Avatar Reviewの操作項目、水着と素体の初回確認コードを消さず、追加オプションとして実装する。

## 宇宙資源

- 既存の航行・索敵座標系に、小惑星の C/S/M 型など計5つの資源コンタクトを追加した。星系の重力で運動する実際の小惑星帯・公転軌道は **未実装**。
- カメラのHUDから目標を選択、またはQuestの中心視線を約0.85秒保持すると鉱床を選択する。操縦席に着席して、宇宙航行中・1.5km以内で兵装の発射操作を行うと破砕・自動回収する。
- 速射砲／パルス砲／ミサイルに応じた回収量、兵装クールダウン、ミサイル消費、倉庫上限360kg、鉱体ごとの残量を試験的に導入。敵への攻撃ロックとは別管理。回収・精製データは `shipSystems.industry` に保存し、従来セーブデータでは初期化する。
- 船内「⛏️ 採掘・精製」から鉱床・保管品・レシピを確認。水から推進剤、推進剤から船の燃料補給、鉄・アルミから船体板、板・銅から修理キット、銅・銀・金から電子回路を加工する。プラチナとヘリウム3を使う核融合セルは技術レベル3の拡張枠に置いた。
- **試作の簡略化**：採掘時点で元素相当の回収品として集計する。実物の破砕物の運搬、選鉱、酸化物からの還元・製錬、溶融・鋳造、設備の消費電力、宇宙港取引、貨物質量と船体加速の連成は後続課題。各レシピの `energy` は表示上の必要工程エネルギーであり、ゲーム内ではまだ消費しない。
- **資源値はゲーム用配分**。小惑星の実測組成や採算性を主張しない。特にヘリウム3は一般の小惑星で豊富とは扱わず、太陽風を受けたレゴリス片の微量試料に留め、主たる候補は月面レゴリス等とする。

## アバター

- Avatar V10の保存形式に任意の `anatomy` 設定を追加。旧セーブに項目がなければ全追加パラメータをゼロにし、従来の表示を保つ。元の副官モデル維持・服装・素体・水着・ロック解除・顔と体形のReviewスライダーは変更しない。
- 「🩺 人体構造・軟部組織」から胸筋／腹部／臍／臀部／腕／脚の輪郭、および胸部・腹部・臀部の運動に追随する軟部組織揺れを、素体表示用シェーダーで追加調整できる。
- 口腔・食道・胃・肝臓・腸、骨盤内器官（子宮・卵巣、精巣・前立腺）の学習用名称、説明、位置アンカーを保存可能なメタデータと分離して追加した。これらは**参照ガイドのみ**で、器官3Dモデルや内視鏡・手術・解剖の実装ではない。いずれの性別の人にも医学的な多様性があり、単一のモデルで医学的正確さは担保できない。
- **未完了**：現行のGLBベースメッシュは衣服由来の代替形状・足の代替メッシュを使うモデルがあるため、体表の真のシームレス化（統合頂点、連続法線・UV、腰／足首の継ぎ目消去）は、アーティストが制作した一体型全身ベースメッシュの導入・再スキニングを別途必要とする。今回の変更だけで「完全な継ぎ目ゼロ」とは判定しない。
- 乳輪・乳頭、臍、胸筋と腹直筋はすでに素体限定の体表シェーダーで描写されていた。今回の調整はその上への追加であり、衣服と水着には表示しない。動的揺れは簡易的な頂点変形であり軟部組織物理・医学用シミュレーションではない。
