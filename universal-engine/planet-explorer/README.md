- **惑星時間の時刻表:** 外回り「蒸気環状1号」と内回り「蒸気環状2号」を惑星標準時から決定的に運行。駅ごとに次発6本、発車時刻、方向、次駅、発車までのカウントダウンを表示する。2列車の停車駅／走行区間／区間進捗／到着予定もライブ表示する。

## v0.8n — 歩ける帆船、船室と甲板、乗組員・操舵担当（2026-10-19）

- **最初から仲間と乗船：** 海洋の「中型帆船の甲板へ降下」では既存の仲間 **斥候・職人** も同じ船に乗船。斥候が初期の操舵担当で、プレイヤーは船内を自由に移動できる。すでに部隊が追加されていれば乗組員も乗船可能（上限24名）。旧帆船セーブからも配置と操舵担当を復元・補完する。
- **独立した船内歩行：** 船体の地理座標・速度と、人物の船上ローカルX/Zおよび甲板／船室の区画を分離。甲板上は手すり・船首・船尾に沿った歩行境界、船室は壁の内側が有効範囲。**スティック／WASDで歩行、床をダブルタップすると本人だけが船内を歩く。** 航行中にも船内の人物・家具が船体と一緒に移動する。
- **開閉できる船室の扉：** 甲板・船室で扉の近くまで歩き、扉をタップして開ける。もう一度扉をタップするか「扉を通る」で甲板⇔船室を行き来。扉の開閉が3Dモデルの回転に反映される。NPCも部屋を切り替える際は扉へ歩き、自分で扉を開けて行き来する。
- **操舵分担：** 操舵中のアバター・仲間は後部舵輪の位置に留まり、**操舵担当本人だけがスティックを船の移動・舵に使える**。担当が仲間なら、操舵パネルは「左舵・右舵・巡航」命令としてその担当に伝わり、プレイヤーのスティックは甲板移動に使える。「舵輪へ歩く」でプレイヤーが舵輪まで歩き、到着すれば操船を引き継ぐ。担当者不在時は新たな操舵・巡航指示を受け付けない。
- **自律NPC・会話：** 操舵していない仲間は甲板と船室の間を移動し、歩行・釣りの様子・休息・会話などを自律的に切り替える。実際の魚獲得はプレイヤーの釣り操作でのみ発生（自律釣りで資源が無限増殖しない）。同じ船内区画の3.5m以内で仲間をタップまたは「💬 仲間と話す」を押すと台詞と吹き出しを表示。操作は「☰ 操作 → 🌊 海・船 → 🧑‍✈️ 乗組員・甲板歩行」。
- **生活との連携：** 船室のベッド、椅子、調理台、食卓、本棚の既存動作を残し、船室の3D家具を直接タップして使用可能。甲板で竿を出した際は竿・ウキを現在の歩行位置から表示。船体の巡航によって人物の体力を消費せず、本人の実際の歩行だけをスタミナなどの消費判定に用いる。船の位置、乗組員の座標・役割、船室／甲板の状態、扉の状態を同じ船専用セーブに保存。
- **現段階の限界：** 船の物理演算・帆を操作する乗組員の専用モーション、複数階層・マルチ船舶での全船員継続生活、仲間同士の動的な深い会話や NPC 独自の釣果加算はまだ対象外。船内生活はこの1隻の船体に結び付く独立した座標空間で実装した。実機での長時間航海とiPhone Safariの総合操作は未検証。

## v0.8m — 船室生活・釣り・惑星一周の航海記録（2026-10-19）

- **船室:** 中型帆船の甲板から「☰ 操作 → 🌊 海・船 → 🚪 船室に入る」。船体モデルに独立した居住空間のカットアウェイ表示を追加し、船室の家具は3Dモデルをタップして操作できる。船室を出ると甲板へ戻る。船室にいる間のスティック／地面ダブルタップは操船・移動の誤入力を避けるため無効。
- **使える家具:** 🛏️ ベッド=睡眠と空腹を消費した体力・メンタル回復、🪑 椅子=着席休息、🍽️ 食卓=持ち込んだ料理を食べて満腹回復、🍳 調理台=魚1＋薪（木材）1から料理1、📚 本棚=航海日誌を読む・携行本にアクセス。ランプを含めた船室内装を立体表示。既存のキャラクター状態・食事・読書と連動。
- **航行と船室:** 操船者が船室に入っても船の巡航設定は維持され、船室行動と船の移動を分離した。海へ飛び込む際は船室から甲板へ出てから実行する。船室入退出・直近の行動を船専用のセーブに保存。旧船保存の互換性を維持。
- **釣り:** 船の甲板／浜辺から仕掛けを投げ、6〜16ゲーム秒でアタリが発生。28秒以内に「🐟 引き上げる」で獲得し、逃すと再投げ。アジ／サバ／タイ／サンマ／イカ／マグロを軽量抽選。釣果は共有資材「🐟 魚」として1匹ずつ加算、魚種は釣果ログへ記録。釣り竿と海面に浮くウキを表示。船室や水泳中は釣り不可、ゲーム一時停止中は釣り時間も停止。釣り状態は船専用セーブに保存。
- **惑星一周:** 惑星の球面地理は大円移動・経度±180°接続を保持。船の緯度・経度は地球儀と共通で、現在座標、累計航行距離、経度方向の回転率、達成周回数をHUDに表示。単に同じ海域を巡る・遠くへ移動するだけでは達成にならず、経度の累積360°と惑星周長の80%以上の航海、出発点近傍への帰還を満たして初めて一周を記録する。離れた船の再乗船も現在位置からの球面距離で照会し、国際日付変更線越えや一周後も短距離検索が働く。
- **限界:** 複数の海陸地形を迂回する自動航路探索、世界規模の全施設・資源の動的な位置再基準化、季節風と海流、甲板内の自由歩行や船室の完全な扉アニメーションは未実装。周航判定は地理計算の自動テストで確認したが、実際に長時間操船して惑星一周する実機検証は未完。航海速度8.5m/sはゲーム調整値であり現実の所要時間を表さない。

## v0.8k — 着弾矢の消滅・外洋用中型帆船（2026-10-19）

- **矢の回収期限:** 地面・木・建物・訓練標的・敵に刺さった矢は**着弾後90ゲーム秒**回収でき、その後自動的に消える。矢筒の容量・移動して回収する既存機能はそのまま利用。時間停止中はカウントしない。残り時間は矢のスナップショットに保存、以前の保存から復元した旧形式の矢にも90秒を設定する。
- **選べる海洋降下:** 惑星地表を指定した際に、従来の「🏝️ 陸上」「🏊 水面」に加え「⛵ 中型帆船の甲板」を選択。甲板開始は海水域のみ、川や陸地には船を生成しない。降下した地点に中型帆船を配置し、すでに同じ場所にある船があれば再利用する。降下船はシナリオ用の初期装備であり、造船資材は獲得しない。
- **中型帆船:** 17mの低ポリゴン船体に甲板、船室、舵輪、2本の帆柱、帆とロープを描画。帆は畳む／半帆／展帆の3種類の外観。クラフトは木85、板材45、繊維45、金属8。従来のいかだ・手こぎ舟の操作や造船コストを維持。
- **操船:** 「☰ 操作→🌊 海・船」に帆の開度0～100%、左舵・右舵、巡航開始・停止、投錨・揚錨を追加。徒歩での移動とは独立した**外洋帆船の移動速度8.5m/s（帆100%時のゲーム値）**。スティック・WASD・ダブルタップは船上からの操船に使い、帆の開度を速度へ反映。帆船の目的地指定は最大6km。
- **航海中の乗降:** 船上でもいつでも「下船・海面へ」で泳ぎを開始し、帆走中の船は巡航設定によって自律的に航行を続ける。32m以内なら接近して再乗船が可能。岸の24m以内に下船すれば浜辺へ上陸。投錨で巡航を解除して船を停める。未乗船の船の位置・帆の状態・巡航状態・錨は既存の船専用ジャーナルと手動セーブへ保存。
- **制限:** この段階では船の相対移動と操船を一体として扱い、甲板内の自由歩行・船室内の移動・乗組員管理・風速による実風向風上性能・風浪での船体傾斜などは未実装。操船速度はゲーム用の仮値。遠く離れた巡航中の船には泳いで追いつけない場合がある。

## v0.8j — マップ一覧とダブルタップ操作の分離（2026-10-19）

- **ダブルタップ優先:** モバイル・PCの3D画面で、最初のシングルタップによる動物・対象ウィンドウを約320ms遅延。2回目が同じ位置に来たら1回目の選択を破棄して地面へ移動指示を送る。動物・建物・資源が重なる位置でもダブルタップは移動優先。RTSでは人物の再選択より部隊移動を優先する。海上や建築配置モードの制約は従来通り。
- **通常のタップ:** 1回のタップだけなら動物のウィンドウや資源選択、人物のRTS選択は引き続き利用可能。指のドラッグ・2本指ピンチ時は保留中の選択を取り消す。

- **互換性:** 既存セーブや動物、農耕、海洋システムのデータ形式は変更なし。対象一覧や選択リングは一時的な画面操作でありセーブしない。Safari向けにエントリーと関連モジュールのキャッシュクエリを更新。
- **制限:** 資源の一覧は無限惑星の全リソースではなく、現在3Dレンダラーが読み込んでいる地形の対象を表示。建物内装や店舗会計など未実装の詳細画面を勝手に起動しない。

## v0.8h — 空腹・体力・メンタル・HPの連動と治療（2026-10-18）

- **状態連動:** 満腹度（100=満腹、0=飢餓）ゲージを左上HUDへ追加。ゲーム実行中の時間経過で少しずつ減り、移動・作業で消耗が増えます。HPの自然回復はゆっくり（毎秒最大約0.028HP、休息中は約0.095HP）で、回復したHPに応じてスタミナと満腹度を消費。満腹8以下、スタミナ12以下、HP0では自然回復を停止します。回復条件の効果はゲーム仕様上の数値です。
- **メンタル:** 戦闘ダメージを受けた直後に精神ダメージ。満腹度25未満、スタミナ25未満が続くと時間とともに低下します。HPが30%未満でもわずかに負荷がかかります。十分に食べて休めていれば緩やかに回復します。
- **回復手段:** HUDの「食事・休息・治療」に「食べる（料理／リンゴ／ニンジン／食材／バッグ内食料）」「休む（小回復）」「寝る（小屋／テント／ベッドロールの近くで大きく体力回復）」「回復薬（HP最大45、薬1個消費）」「回復魔法（HP最大38、メンタル20消費）」「教会（8m以内・HP最大85、体力＋メンタル回復）」を追加。回復薬は初期2個を持ち、薬屋8m以内で繊維3・水1を消費して1個調合できます。
- **教会:** 施設カタログに⛪教会（木18・石22・金属2）を追加。配置すると十字架のある建築モデルになり、8m以内で教会治療を使えます。
- **生活・オート:** 人物ごとの satiety, stamina, mental, healingPotions を既存の Frontier 人物スナップショットへ追加。旧セーブは Lifestyle の「空腹感」（高いほど空腹）を反転して移行。従来のテーブル／椀の食事、家具・テントでの睡眠もゲージに反映。自動行動の条件変数に「満腹度」と「メンタル」を追加。
- **セーブ:** 手動セーブの `v0_8h.playerHp` にプレイヤーHPを保存。人物の状態値は従来の部隊スナップショットに保持。ローカル生活ジャーナルへもHPと各人物の状態を約10秒ごと／操作時に保存。旧版の保存キーは維持。
- **限界:** 現時点では軽量な代謝シミュレーションで、病気・感染症・栄養素・詳細な魔力システムや教会NPC診療は未実装。iPhone Safari実機の画面描画・FPSは別途検証が必要です。

## v0.8g：農耕・放牧・果樹・丸太の寸法製材

- 「☰ 操作 → 🌾 畑・果樹・製材」で、降馬した開拓者が正面3mに1区画の畑を耕せる。水域・急斜面・近接区画への施工を防止。
- 畑には小麦（6惑星日）、ニンジン（4惑星日）、リンゴの果樹（初回16惑星日・その後12日ごと）を植えられる。農業専用の種から始め、収穫すると種も増える。果樹は一度植えると繰り返し実る。日数は「＋1日」「＋90日」の操作で進められる。
- 小麦の収穫物は小麦×4と麦わら×5、ニンジン×5、リンゴ×6（試験用固定数量）。収穫物は共有資材として保存。
- 野生馬・オーロックス・ムフロン・ベゾアールヤギ・セキショクヤケイは、立ち止まって頭を下げ、草を食む/ついばむ動作をし、満腹度を回復する。犬・猫の野生祖先は草食み対象外。
- 動物の「🍽️ 餌を与える」は飼料を1個消費。馬・ウシは麦わら/ニンジン/リンゴ、ヒツジは麦わら/ニンジン、ヤギは麦わら/ニンジン/リンゴ、ニワトリは小麦。近くの動物へ手渡しできる。牛・羊・山羊・鶏も3回の馴致で追従可能。「🌱 放牧する」で追従を解除し採食状態に戻せる。
- 「🪚 近くの倒木を指定長で切る」では切断長さを0.1〜12.0mで入力。道具の製材モーション完了後、倒木の総長から指定した長さ分を切り分け、製材済みの寸法/質量/残材長を記録する。同じ倒木を何度切っても資源総量が増殖しないよう差分で配分。残りを斧で回収する場合も切断済み分を除外。
- 農業・畑の成長・動物の満腹度・丸太の残り長さは既存のセーブデータと共存。各々ローカル自動保存に対応。旧 v0.8f までの保存形式も読める。
- 制限：耕作・種まき・収穫は現状パネル操作（鍬や鎌の専用モーションは未実装）。製材の入力可能寸法は**長さ**のみで、板の幅・厚みの自由設定や積み上げ配置は今後。採食による地面の草の消滅、飼育生産・繁殖・家畜の畜舎管理は未実装。
