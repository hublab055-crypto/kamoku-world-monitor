# Universal Engine v0.9au — スマホ用4アクション・ミニマルUI

更新: 2026-11-01

## 操作

- スマホの通常の冒険画面では、左下の既存スティックと、右下の4ボタンを標準表示する。
- 初期割り当て（徒歩）: A ✋ 調べる・操作、B ⚔️ 攻撃・右手装備、C ⬆️ ジャンプ、D 🎒 持ち物。
- 4ボタンの短押し・長押しはそれぞれ個別に割り当て可能。長押し判定は520ms。
- RTSには独立した4ボタンの割り当てを用意する。従来の5行動デッキは消さず、ゲームロジックを共有する。
- 「☰ 操作」→「🎮 スマホ操作設定」で各モードの4ボタンを設定する。
- 設定画面のチェックボックスから、従来の道具・ジャンプ、5行動デッキ、コマンドバー、RTS指揮、ドア、弓、状態表示、ログ／QRを個別に再表示できる。
- 表示とボタン設定は localStorage の universal-engine:mobile-four-actions:v1 に保存。保存できない環境では現在のタブ中のみ利用。
- スマホUIは最大幅1024pxかつ pointer:coarse の環境で有効。PC/キーボード、Quest VRに既存操作への変更は加えない。
- 宇宙視点では4ボタンは非表示（☰操作や降下UIを使用）。船や専門画面の固有パネルはそのまま残す。

## 移動スティックとアバターの向き

- スティックの座標は +X が画面右、+Y が画面下。実際の移動方向も画面基準で決まる。
- 触れた瞬間のカメラ方位を移動基準として固定する。三人称追従カメラがアバターと一緒に旋回しても、押し続けている間に移動方位が回り続けることはない。
- スティック入力から向きを計算してアバターを最大9rad/sで旋回。移動速度はスティック倒し量に対応し、旋回途中も指定方向へ移動する。
- VR・キーボード、拘束/乗り物/室内の専用移動、自由カメラ、RTSは既存の制御を保つ。これらへの新しい向き変更は本PRの対象外。

## 実装ファイル

- mobile-controls.mjs: デフォルト設定、保存設定の検証、カメラ相対の移動ベクトル。
- mobile-four-actions.mjs: 4ボタン、長押し、表示設定、localStorage保存。
- app.mjs: 戦闘/ジャンプ/持ち物/会話など既存アクションとの接続、およびスティック旋回。
- index.html / style.css: HUD・設定パネルの設置、スマホ時の重複操作UIの非表示。
- mobile-controls.test.mjs: 設定正規化と移動方向のテスト。

## 制限事項と手動確認

- 「調べる・操作」はドア操作の表示中は開閉/出入り、その他は会話操作に接続する。すべての設備・乗り物に対する万能な近接判定はまだ実装していない。
- 設定は端末ブラウザごとに保存し、ゲーム内セーブスロット/ポータブルJSONへは含めない。
- iPhone Safari実機でのタッチ領域・長押し・画面回転と、Questブラウザ上の全組み合わせは未検証。
- 手動確認推奨: iPhone縦・横、スティック8方向、指を離した後の停止、4ボタンの短押し/長押し、設定保存→再読み込み、RTS切替、旧UIのチェック再表示、VR操作。
