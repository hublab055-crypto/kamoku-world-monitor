# v0.7z — 宇宙から地表への大気圏降下

## 内容
- 既存 v0.7x の全球タップ選択、緯度・経度とプレイヤー座標を維持。ダブルタップ降下／選択後の確定をそのまま使用。
- 降下高度に連動して「宇宙空間 → 大気圏接近 → 大気圏上層 → 雲海 → 山脈・海岸 → 森林・地形 → 地表」と表示。階層は表示用であり、キャラクターの行動・物理や時刻に影響しない。
- `descent-visuals.mjs` で対数高度の変化速度を上限制御。以前の高度補間は雲付近を一瞬で通過していたため、最高速度を制限して各高度帯を見えるようにした。
- 球面表示と地表メッシュの切替は高度23,000mで維持。切替周辺の視覚的な段差を隠すため、大気・雲・霧のスクリーンレイヤーを導入。切替時は高い霧の不透明度が発生し、地上では消える。これは厳密に途切れない幾何学LODではなく、**既存2方式の視覚的な橋渡し**である。
- `orbit-terrain-lod.mjs` は降下に合わせて３段階の細かな局所球面地形タイルを生成し、粗い惑星ポリゴンの見え方を改善。地表メッシュと同じ `terrainSurface` を利用するが、GPU上だけの軽微な高さ持上げを行う。保存値・歩行判定・地表標高は変更しない。
- 惑星の雲デッキ半径を実効高度約13kmへ補正（以前は約85km）。雲内部では画面上の雲影を重ねる。
- スマホでは雲レイヤーを入力透過とし、タップ・ピンチ、RTSとアバター操作、ログを妨げない。動きを抑えるOS設定なら雲アニメーションを停止。

## 制限と注意
- 物理的に正しい大気散乱・流体雲・衛星画像・遠景DEM融合ではない。高度と表示の演出であり、厳密な衝突を行う雲粒子ではない。
- 惑星全域の建築／資源の永続化、海上の移動、降下中の航空機操縦は未実装。
- 地表の世界座標／セーブ形式は変更しない。旧バージョンはそのまま保持。
- WebGL2／iPhone Safariの実機描画とGitHub Actions全回帰テストは独立した確認が必要。重いスマホ環境での描画負荷評価が残る。
