# v0.9o: 国債・都市公債と公金庫（ローカル試作）

## 操作
1. 惑星探索画面の **🏛️ 財政・土地** を開き、自領（初期は開拓地）を選びます。
2. **公債を発行** します。額面は10/50/100G、10〜100口、満期は3/6/12か月、満期利率は10/20%。発行自体は公金庫の増加になりません。
3. **債券を購入** すると「街の生活」のプレイヤー所持金から「発行元の公金庫」へ購入代金が移動します。
4. 満期到来後、国庫に元利金と同額以上の残高があればプレイヤーへ自動返済します。足りなければ返済遅延となり、ゲーム内月ごとに支持度が下がります。未払い元利金は債務として残ります。

## 例
- 開拓地が額面10G×20口、満期3か月、満期利率10%の公債を発行。
- プレイヤーが2口購入: 所持金 −20G、開拓地公金庫 +20G、未払元利金 +22G。
- 3か月後に返済可能なら国庫 −22G、プレイヤー所持金 +22G。
- 利率は**満期までの総利率**です。単利・満期一括返済であり、毎月の複利ではありません。

## 財政上の注意
- 国債収入は税収ではありません。国庫が増えても元利金の返済債務が生じます。
- 住民所得税は従来どおり**ゲーム内30日ごと**に確定します。国家外交・軍事の毎月の維持費はその後に差し引かれるため、純増が小さい場合があります。
- 国債の発行・購入はローカルセーブに残ります。既存のterritory schemaVersion=1にも `bonds` オプションを加える後方互換形式で、古いセーブは空の公債台帳として読み込みます。
- これは単一プレイヤーのオフライン用試作です。NPCの財布、任意の他プレイヤー口座、取引所での転売、部分償還、オンラインの所有権認証、複数の保有者への分配は未実装です。マルチプレイ時はサーバー側の原子的な帳簿・残高更新が必要です。
- プレイヤー財布の上限（999,999G）を超える返済は、資金を失わないよう上限が解消されるまで保留されます。

## テスト
`cd universal-engine && npm test`
公債の発行・購入・不正購入拒否・二重償還防止・返済遅延・セーブ移行・ウォレット上限を検証します。
