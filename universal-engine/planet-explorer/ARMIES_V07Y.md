# Universal Engine — 冒険者パーティ・中隊・敵部隊 (v0.7y)

## 使い方
地表で **⚓ RTS視点 → 👥 部隊管理** を開く。
- **🧭 冒険者パーティ（6人）**: 剣士・槍兵・斧兵（前衛） / 弓兵・魔法使い・回復役（後衛）。
- **🛡️ 中隊を編成（50人）**: 槍兵20、剣士10、弓兵10、魔法使い5、回復役5。
- 部隊管理の **⚔️ 前衛・後衛** で職種別の列を設定。既存の横隊・縦隊・楔形・方陣と同様に、部隊ごとに集合地点と隊長追従を保存できる。
- 敵は **⚒ 道具 → 👹 敵部隊を出現** から盗賊小隊（10体）または魔物戦団（18体）を生成。単体敵の出現ボタンも維持。

## 編成人数
初期3人に対し、パーティは6人、50人中隊は50人の **独立した追加アバター**を作成する。中隊のみで53人、パーティと中隊の両方なら59人。プロトタイプの上限は味方80人、敵80体（単独テスト出現ボタンは従来の10体制限）。一人ひとりに役割、HP、位置・移動コントローラー、保存データを持つ。旧版の3人固定セーブと互換。

## 戦闘 AI（プロトタイプ）
- 槍・剣・斧は前衛で近距離攻撃。弓兵は38m射程で通常の矢プロジェクタイルを発射し、所持木矢を消費。魔法使いは28m射程でダメージ、回復役は14m以内のHPの少ない仲間を回復。
- これらは配備した兵士のローカル自動戦闘であり、プレイヤーが個別指示した移動、隊長追従、装備使用、条件分岐の行動を可能な限り優先する。
- 敵単独ユニットは近くの味方を探し、敵部隊は集団内で攻撃対象を共有して味方を撃破しようとする。味方のHPが0になると戦闘不能、移動と攻撃は停止。隊長が戦闘不能になっても残りの隊員が隊形追従を続ける。
- 敵味方のHP計算は戦闘テスト状態に限定。隊員HPはセーブされる一方、テスト敵はゲーム全体の既存セーブには保存しない。
- 弓は既存の矢の衝突システムを利用。魔法の専用3D発射体やパーティー専用の高度な経路探索、敵AIの包囲行動、兵站・補給、MPやクールダウンUI、倒れたキャラの死亡モーションは別途拡張が必要。

## 描画と操作
- 50人規模では描画負荷を抑えるため、優先人物以外は軽量な関節モデルを表示。RTS画面のラベルを間引き、詳細な自動行動の人物選択はセレクトボックスで操作。
- 複数部隊の同時選択・登録隊列・同期行動を引き続き利用できる。

## テスト
`universal-engine/tests/large-party-company-battle.test.mjs` で人数、役割、前衛・後衛位置、セーブ復元、上限、敵部隊、回復・魔法・射撃を検証。

`cd universal-engine && npm test`
