# 目標選択航法と大気圏突入（2026-11-08）

大気圏突入条件から「自動操縦OFF限定」を撤去し、自動航行で惑星へ到達した際も既存の安全地形準備→突入→高度700mでの大気圏内航行へ進む。以前は自動操縦が周回軌道で停止しており、描画上接近しても突入しなかった。

惑星・敵・資源・味方・中立のHUD文字またはマーカーをタップすると航行目標として選択する。自動操縦ONで選択目標へ機首を回し、3D航路座標で加速・減速して接近する。非惑星は約80mで距離を保ち、移動目標は各フレーム位置を更新して追航する。目標喪失時は自動操縦をOFFにする。非敵性への攻撃ロックは行わない。

航行目標はセーブに保存。選択目標は白枠と航路欄の名前で示す。タップ選択は通常画面の機能で、Questの視線選択による全種類の航行目標選択は未追加。
