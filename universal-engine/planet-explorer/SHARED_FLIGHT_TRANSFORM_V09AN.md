# v0.9an：停泊から飛行・接地まで共通の船体Transformを使う

更新日：2026年11月1日。v0.9ak〜amの続き。

## 今回の結果

`StarshipEntity`を追加し、一機の宇宙船に同じIDと表示用の位置・姿勢を与えます。アプリと描画器は同じEntityインスタンスを参照します。既存のSurfaceStarshipは停泊位置とハッチ、ShipJourneyは航路・座席・進行状態を扱い、その入力から共通Transformを求めます。

これは**表示用の運動モデルの統合**です。推力・重力・慣性・速度を積分する飛行物理や、全ての機体属性を一つの物理Entityへ移す変更ではありません。

| 段階 | 共通Transformの位置・向き |
| --- | --- |
| 停泊 | 天体固定座標の着陸地点。床は機体設置基準から2m |
| 上昇 | 同じ地点の上方へ上昇。高さ・旋回は始終端で滑らかにつなぐ |
| 出発側の軌道 | 上昇終端と同じ位置・姿勢 |
| 巡航・接近 | 同じ時刻の出発／到着天体位置を使うパラメトリックな星系座標の曲線。姿勢はQuaternion補間 |
| 到着側の軌道 | 巡航終端と同じ、確定した着陸地点の上方 |
| 降下 | 軌道位置から確定済みパッドへ降下し、最終方位へ整える |
| 接地・着陸完了 | 同じパッド・方位・高さで停止。地表機体へ戻しても姿勢を保つ |

ゲーム用の軌道高度は従来の上昇表示と同規模の7,000mです。実際の安定軌道を計算した高度ではありません。上昇・降下には五次補間を使い、位置と姿勢の境界を合わせます。これは各段階の位置・姿勢の整合であり、力学的な速度・加速度の連続性を保証するものではありません。

## 窓の外の描画

- 近傍地形は、地理座標に固定した地形パッチから共通の船室座標へ変換します。地形を独立した演出値だけで上下させません。
- 出発地域のキャッシュ景観も、そのキャッシュの地理アンカーから船室へ変換します。別天体の降下時に出発地の街を表示しません。
- 惑星・衛星・恒星の向きと角サイズは、同じ星系時刻・船体Transform・観測者の目の位置から求めます。進行率だけで前窓に惑星を固定配置・拡大する方式は、新しいShipJourneyでは使いません。
- 星系の巨大な絶対座標をそのままFloat32へ送りません。カメラ相対の方向と角サイズを保って遠景パスへ渡し、近景の地形と船室を後から同じキャンバスへ描きます。
- 降下中だけカメラを自動で傾ける旧演出は外し、船体の姿勢と船内の見回しを組み合わせます。旧SpaceVoyageは従来の表示経路を残します。

惑星球体は現在も簡易メッシュです。大陸・海岸線を全高度で一致させる惑星全周LOD、大気散乱、厳密な地平線・遮蔽の実GPU検証は別段階です。

## 到着地点の固定と再開

目的地の航路設定時点で地形を準備し、安全な着陸パッドを航行記録に確定します。降下前の再評価、実際の地表世界への切替でもその地点を使います。確定済みパッドが不適合・高さ不一致になったときは、別地点へ無通知で移動せず、既存の航行エラー復帰処理へ返します。

`landed`だが現在の天体が到着先でない保存では、地表世界への切替が未完了と判断し、再開時に一度だけ切り替えます。すでに到着先にいる場合は繰り返しません。

## 保存形式

`v0_aa.shipEntity`へ任意の追加ブロックを保存します。

- format：`ue/starship-entity`、version：1、motionModelVersion：1。
- 機体ID、参照した天体モデル、現在のframe ID・位置・基底、星系位置・基底、時刻、着陸地点等を保持。
- ShipJourney schemaVersion 2、SurfaceStarship schemaVersion 1、既存スロット・携帯セーブの基本形式は維持。
- 出発地点のパッド高さをlaunchSiteへ保持。旧v2で欠落している高さは、出発世界がある間に地形から一度解決。
- Entityブロックのない旧セーブは既存の航行状態から表示姿勢を導出。元データに地点がない場合は`legacyDerived`として区別し、失われた旧版の実位置を完全に復元したとは扱わない。
- 未対応の座標モデルversionや不正な位置・基底は明示的に拒否。保存内の世界やNPCを初期化して読み替えない。

チェックポイントは表示用のモデルです。旧版ソフトウェアへ戻して再保存した場合に、この追加ブロックを保持する保証はありません。新版での再開検証を対象とします。

## 検証

今回12件を追加し、関連70件が成功しました。

- 停泊→上昇、上昇→軌道、軌道→巡航、巡航→到着軌道、軌道→降下、降下→接地、接地→着陸の端点で星系位置と姿勢が一致。
- 全飛行段階での保存・復元、出発パッド高さ、機体ID、未知version・不正チェックポイントの拒否。
- 地形から船室への行列、手動の進路偏差と船外の姿勢、観測者位置を含む天体角サイズ。
- TerraとSelene／Cinder／Nix間の各サンプル航路で基底が正規直交し、出発・到着天体の内部へ入らないことを確認。ただし全時刻・全障害物の衝突回避を証明するものではない。
- 実際のExplorerRenderer＋WebGLモックで、同じEntity参照を使った上昇・星系巡航・目的地形描画・保存復元を確認。
- 全体：前段階715件中667件成功・48件失敗、変更後727件中679件成功・48件失敗。失敗テスト名の集合は同一、新規失敗0件。
- JavaScript構文・差分空白検査を実施。Safari・Quest・実GPUの表示品質とフレーム時間は未確認。
