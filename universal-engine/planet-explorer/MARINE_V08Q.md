# Universal Engine v0.8q — 釣竿装備・飛び込み・潜水・目的地マップ

## 🎣 装備から釣る
1. 画面の🎒持ち物→「🎒 持ち物一覧から装備を選ぶ」を開き、右手または左手に **🎣 釣竿** をセット。釣竿は基本装備として最初から所持します。
2. 船の甲板か海岸で **「🫱右手」または「🫲左手」を押して「使う」**。キャストパワー設定の強さで竿を投げ、画面上に小さな巻き取りダイヤルが開きます。
3. リールを時計回りに回すと糸が巻き取られます。魚が掛かっていないときも空巻きできます。命中するまで待つ／ダイヤルを回す操作は既存の釣果・保存データと互換です。
4. 「✕終了」で釣りを中止。従来の「🌊 海・船→🎣釣り」画面からもキャストゲージやダイヤルを使えます。
5. 釣竿は装備すると手元の3Dモデルとして描画し、キャスト・リール操作に応じて腕を動かします。

## 🌊 海に飛び込む
1. 船の甲板や海岸で、近くの水面を **ダブルタップ**。
2. 「🌊 飛び込みますか？」確認画面の「🏊 飛び込む」を押す。
3. 腕を伸ばす跳躍ポーズと着水波紋を再生して水面に入ります。船は元の座標に残り、航行中であれば既存の航海処理を継続します。
4. 水泳中に水面をダブルタップすると「🤿 潜水しますか？」と表示することもできます。
5. 船室からは飛び込めません。扉を通って甲板へ移動します。

## 🤿 潜水操作
- 水面に入ると、ゲーム画面に **「↓ 潜水」** を表示します。
- 水中では **「↓ 5m」「↑ 5m」「↑ 水面」** で深さと浮上を制御。
- 既存の酸素ゲージ、装備による潜水可能深度、海底遺跡・船骸モデルを引き継ぎます。
- 最初から手持ちのアクアラングは「🌊 海・船」の装備変更で装着できます。
- 装備性能はゲーム用の仮設定で、実際の潜水安全指針ではありません。

## 🗺️ 地図から移動する
1. 「☰ 操作 → 📍 目的地マップ」、または「🗺️ マップ一覧 → 📍 地図を開いて行き先を指定」。
2. 上が北、右が東の地図を表示。青は水、緑は陸、黄色は砂浜・島です。現在地は中央の白い矢印です。
3. 表示範囲を90m、160m、300m、600m、1.2km、3kmから選び、行きたい地点をタップ（キーボードも対応）。
4. 方角・距離と地形を確認し、 **「📍 ここへ移動」** で目的地をセット。徒歩最大350m／騎乗最大1.2km／船最大6kmなど従来の距離・地形制限を適用します。
5. 移動は瞬間移動ではありません。地形衝突で停止する直進航路です。障害物を避ける自動経路探索や惑星全域の連続航路は未対応。
