# Universal Engine: ヘリオス恒星系（試験版）

更新日：2026-10-31

## 操作
1. ゲーム画面の「☰ 操作」から「🪐 恒星系」を開く。
2. 恒星系配置図と地上から見える天体の簡易天空図（方位と高度）を確認する。
3. 「🚀 操縦席へ」を選ぶと宇宙船が準備される。操縦席で離陸・スロットル・左右旋回・自動航行を操作し、周回軌道で着陸を選択して別天体へ降りる。同行者、手持ちアイテム、資材、通貨は引き継ぎ、建物や土地編集等の現地開拓記録は元の天体に残る。地上移動や会話等の操作は従来のものを利用する。
4. 小惑星帯は宇宙視点で「☄ 採掘」を使用する。採掘は簡易抽選であり、小惑星表面への着陸や本物の探査機操縦ではない。
5. 既存のセーブボタン、スロット、JSON書出しで恒星系と各天体の記録を保存できる。

## 天体と環境
- Terra Nova: 温暖、海と植生、24時間自転、365.25日公転
- シンダー: 乾燥した岩石惑星、弱い重力、薄い大気、鉄鉱石中心
- ニクス: 氷・鉱石の低温惑星、長い自転周期
- セレーネ: Terra Novaの衛星、ほぼ真空、低重力
- ゼファー: 巨大ガス惑星（観測のみ、着陸なし）
- アステリア小惑星帯: 軌道表示と探査機採掘（資源加算）

恒星ヘリオスを中心に各天体の軌道位置を共通の日付から計算する。地表の観測図は自転角、観測者の緯度経度、距離から位置・見かけの角直径を計算する。軌道はゲーム向けの単純化された円軌道であり、ケプラー楕円軌道・摂動・Hohmann遷移・日食判定は未実装。

### 現在の制約
- 地表観測は画面上の簡易天空図、方位追従の天体観測ガイドと天体名のHUD。WebGL空間に見かけの大きさで天体メッシュを描く機能や、実物のような日中の散乱・月相は未完成。
- 宇宙船の離陸・巡航・接近・着陸操作は簡易モデルとして実装。3D船室、正確な軌道遷移、惑星間の物流・実物の燃料・生命維持・基地の環境ハザードは未実装。
- 別天体は地形シード、標高、乾燥／寒冷気候と鉱物系の採集対象を分離。植物、動物、建物、社会活動の惑星別の生態学的な完全分離は今後の課題。
- 重力値は天体属性に含まれるが、歩行、ジャンプ、弾道、落下のすべてを実重力に統一する作業は未完。
- 恒星と惑星の軌道表示は距離の縮尺を圧縮し、採掘と航行期間は暫定値。
- 旧セーブとの互換性を維持するため、新データは `v0_aa.solarSystem` と `v0_aa.voyage` に格納。対象を変更する前にセーブスロットやJSONを別途バックアップすることを推奨。

### コード
- `solar-system.mjs`: 恒星系データ、天体位置、可視性・観測座標、惑星モデル、共通時計、採掘、スナップショット
- `solar-system-ui.mjs`: 恒星系マップ、観測図、航行選択・小惑星採掘
- `solar-terrain.mjs`: 乾燥・氷天体の地形プロファイル
- `solar-transition.mjs`: 別天体セーブと携行品の切替
- `space-voyage.mjs` / `space-flight-ui.mjs`: 段階的航行・コックピット・航行途中の保存復帰
- `celestial-sky-viewport.mjs`: 地表で太陽・惑星・衛星の向きを表示
- `app.mjs`: 保存・画面と各モジュールの接続
- `solar-system.test.mjs`: 数学・移動・環境・保存のNode.js単体テスト

### 今後の推奨実装順
1. WebGL天空図（太陽、月、惑星、星座）、惑星別の軌道グローブカラーと月相、日食。
2. 3D船体、燃料・酸素・電力、自由な船内歩行、実際の軌道遷移とVRでの操縦（簡易航行の高度化）。
3. 惑星別資源・鉱脈・建築素材・生命維持と極限環境・気圧・温度のダメージ。
4. 小惑星の実メッシュ、鉱物掘削、資源貨物船、宇宙ステーション、交易路。
5. 惑星を跨ぐ国家・所有権、複数植民地の行政、経済・外交・RTS連動。
