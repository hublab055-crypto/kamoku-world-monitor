# v0.9ap 操縦席コンソール

2026年11月1日。既存の航路に沿うゲームモデルへ操作を追加。

- スティックの横軸をヨー／ロールで切替、縦軸はピッチ。円形制限と中央デッドゾーンを使用。押下解除・キャンセル・キャプチャ喪失・フォーカス喪失・離席・UI閉鎖で解除する。
- アクセルは既存スロットル。ブレーキレバーは航路進行速度を0〜100%抑制し、最大で停止する。慣性・逆噴射・物理速度の計算ではなく、燃料計算は従来どおり。
- 姿勢操作は着席中のみ、手動優先で自動OFF。自動ONでヨー・ピッチ・ロールを復元。姿勢を共通船体Transformへ反映し、地表端点ではパッド姿勢へ戻す。航路そのものの方向や目的地点は変更しない。
- ギア状態は飛行中・降下前に切替。格納中は降下を拒否し、停泊・降下中の格納を拒否する。ギアの形状・展開アニメーションは未接続。
- 停泊中は着席したままハッチを遠隔開閉できる。「人員乗降の準備」は停泊中にハッチを開き、プレイヤーを操縦席から立たせる。以後は従来の徒歩下船を使用する。NPCへの乗降指示や一括移送は未接続。
- 火器管制と物資投下は未接続と表示し無効化。武器・弾薬・照準・対象判定、積荷の減算・投下物の永続化・着地点への生成を接続するまでは実行しない。
- pitch/roll/brake/gearDownを既存ShipJourney v2へ追加保存。旧保存では0/0/0/展開を使用。入力の押下状態は保存しない。

検証：関連92件成功。全体744件中696件成功、既存48件失敗と同じ失敗集合で新規失敗なし。姿勢上限・保存・共通Transform・ブレーキ・ギアとハッチの制約を検証。実ブラウザのスティック操作、Safari、Quest、実GPUの見た目は未検証。

残る設計：6自由度の速度と推進モデル、自動航路への復帰、ギアの接地形状、火器管制、実体を伴う物資投下、NPC乗降。既存地域origin・NPC・建物・鉄道の永続座標は変更しない。
