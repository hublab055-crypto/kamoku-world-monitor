# 画面端HUD・惑星への接近修正（2026-11-08）

画面外の方向表示は、画面中心から対象方向へ伸ばした線と表示枠の交点に必ず置く。後方で画面中央近くへ戻っていた正規化処理と左右反転を修正。真後ろは右端を選び、「後方」を表示する。横長・縦長で枠内余白5〜8%の端を使用。

巡航中の惑星を船から425mの球面へ正規化していた処理を撤去し、航行モデルの固定終点(0,0,12000m)を描画・HUDで共用。接近すると見かけの距離が減り、巡航中の球体は固定半径300m。自動周回停止時は見通しを保つ軌道用半径80mを使用。上下・左右を同時に向けたときの座標変換順も推力方向と一致させた。手動で軌道／出発軌道から直接接近した場合も、既存の進入範囲に達すると大気圏へ移行できる。

航路は引き続き正規化モデルで、AU表示は実天体間距離に基づく推定。無推力時の慣性は維持する。
