# Universal Engine — 島・投げ釣り v0.8p

## 上陸可能な離島

- 惑星の海域に独立した島が疎に生成されます。島が存在しない広い外洋海域も残ります。
- 島は**本当の地形**です。惑星のTerrain.sample（height/water/category）、地上のterrainSurface、歩行判定・資源・既存の建築システムを共有します。島では歩行、資源採集、既存の小屋などの建築／居住が可能です。
- 海岸に船で接近して「🏝️ 上陸・下船・海面へ」を選ぶと、岸が船の24m以内にある場合は上陸します。岸がないときは無理に陸地へ移動せず水泳になります。
- 「🔭 周囲の島を探す」で半径180kmの実際の島候補を探し、海域によって発見方位・距離、または発見なしを返します。航路の自動生成／自動接岸はまだありません。
- 球体の通常メッシュは陸・海・標高を既存地形に合わせています。小さい島が粗い球体格子で消えないよう **島座標と同じ点から生成した別メッシュ**を宇宙視点に描画。接近時のLOD地形も同じ sampler を使用します。
- 造船や海上降下、既存の中型帆船・船室・NPC・旧セーブの動作を維持します。

## 投げ釣り

1. 島の浜辺／海岸、または船の甲板に移動。
2. 「🌊 海・船」→「🎣 釣り」から **投げる強さ**を10〜100%で指定します。ゲージに応じて約5.6〜29mキャスト。
3. 釣り竿が振られるモーションと飛距離に応じたウキ、近づいてくる魚が表示されます。
4. 魚が接近するとヒット表示。丸い **巻き取りダイヤルを時計回りに指で回す** と糸が約4.2m／回転巻き取られます。キーボードの矢印キーや補助ボタンでも操作できます。
5. ヒットしているときに糸を完全に巻き取れば魚を1匹獲得。**ヒット前の空巻きも可能**で、その場合魚を得ずに糸だけ回収します。魚は一定時間待つと逃げます。
6. 釣り経過、糸の長さ、キャスト強度、ヒットの有無は従来の保存形式に後方互換で追記しています。

## アクアラングの初期所持

- 新しいキャラクターは初回から **アクアラング×1を所持**し、🎒持ち物欄に「手持ち」と表示します。
- 最初から装着はせず素潜りモード。海・船メニューの「アクアラング」を選択して「装備変更」で使用できます。
- 既存セーブを読み込んだ際もアクアラングを1個付与し、既存の他の装備／所持品を残します。

## 検証と未対応範囲

- 島の地形一貫性と球体描画、魚の接近／糸の空回収／ヒット後の巻き取り、棒立ちではない釣りモーション、装備初期所持の自動テストを追加。
- 宇宙の島メッシュの高度は視認性優先のわずかな表示オフセットを使用。上陸・地形判定には影響しません。
- 魚の遊泳／釣り竿は簡易ローポリ3Dです。糸のたわみ、釣り物理、潮目による釣果変動、島の港・住民自動生成や自動接岸は将来実装。
- iPhone Safari/WebGL2の実機目視確認は未実施。
