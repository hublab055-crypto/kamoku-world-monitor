# Universal Engine v0.9al — 宇宙船窓外の物理座標描画

2026-10-31 | 前提: v0.9aj（共通WebGL2船内・地表シーン）、v0.9ak（統一恒星系・惑星・船内座標）

## 達成事項

宇宙船が観測する惑星・着陸予定地を、同じSIメートル／倍精度の恒星系時刻・天体位置から描画するよう変更した。ゲーム的な飛行進行度は既存の `ShipJourney` のままだが、描画位置は進行度に直接結び付いた「画面前方の偽球体」ではなく、`v.framePose(planet.timeDays)` から得られる船体位置と惑星中心の相対位置に従う。

- `ship-planet-view.mjs`: 惑星の本来の角サイズを保った深度圧縮、惑星自転の見かけの方向、着陸地点ローカルへの惑星固定座標変換、球面地形、地表サンプルと同じ高高度の惑星カラーLOD
- `render.mjs`: `renderShipPhysicalScene()` を追加。宇宙船・乗員に対してカメラを固定し、周囲の地形と惑星を毎フレーム船体の実座標から描く。旧 `SpaceVoyage` は従来描画へのフォールバックを維持
- `ship-interior-3d.mjs`: 操縦席の下部ガラスを広げ、窓外の地表・曲がる地平線が見える角度を確保
- キャッシュクエリを更新しSafariが古い船内形状や描画モジュールを再利用しないようにした
- `tests/ship-planet-view.test.mjs`: 角直径、地形LOD、球面曲率、着陸地点の位置整合、元地形と同じ惑星表面サンプリングを確認

## 重要な座標／深度不変条件

1. 座標と時刻は `shipJourneyFrame` / `bodyCenterM` / `surfaceShipFrame` から取得する。
2. カメラに対する惑星中心を**倍精度で差分計算したあと**、深度圧縮する。
3. 球体の中心と半径は同じ比率で圧縮し、実際の見かけの角半径を維持する。
4. 地形パッチ頂点は `R+h` の球面幾何へ変換。平坦な板を無限距離に伸ばさない。
5. 着陸位置の固定フレームから宇宙船のフレームに毎フレーム変換する。船内を歩くキャラクターは船内ローカル座標だけを動かす。
6. 緯度・経度・惑星ID・高度・着陸地は既存のセーブ形式のまま。

## 高度別のLOD

| 船体高度 | 地表タイルの半径 |
|---|---|
| 0〜110m未満 | 650m |
| 110〜750m未満 | 1,850m |
| 750〜3,500m未満 | 6,500m |
| 3,500〜20,000m未満 | 22,000m |
| 20,000〜90,000m | 85,000m |
| 90,000m超 | 球面惑星モデルのみ |

概ね高度1.6〜9.6kmで、曲面地形から惑星球体へ徐々に表示を重ねる。新しい惑星LODの地形色は従来 `geo.samplePatch` と同じ分類基盤を共有する。海岸線・都市の細部まで完全に一致する保証はまだない。

## 現在残る課題

- 惑星全周を解像度可変の地形メッシュで途切れなく描画する、完全な連続LOD/地形テクスチャ管理は未完了。大陸・地形分類は同じシード由来でも、低LODの境界は粗い。
- 球体への深度圧縮は**見かけの角度を維持する描画手段**であり、物理座標や重力を変更するものではない。
- 物理的な操舵、推進、速度ベクトル、船の回転慣性、実際の大気散乱は未実装。船体姿勢は移行中の補間であり、真の6自由度軌道計算ではない。
- 建物・樹木は出発地の近接キャッシュだけ表示。到着地の都市は個別に読み込んでいない。
- WebXR/Quest上の宇宙船航行は既存の制限により対象外。iPhone Safari/Quest実機のグラフィックス検証とFPS計測が必要。
- メインブランチの総合Nodeテストには既存の失敗が残る。新規4件はGitHub Actionsで確認済み。
