# v0.9ao：着席中の操縦と軌道上の進路補正

更新日：2026年11月1日。v0.9anの共通表示Transformに続く操作改善。

## 修正した問題

従来のShipJourneyは移動中のtickだけで自動の進路補正を行い、目的地の軌道上では即座にreturnしていました。手動操作で進路偏差が±12°を超えた状態では、自動航行をONに戻しても着陸条件を回復できませんでした。

出発側・到着側の軌道待機中も自動補正を行い、進路偏差を時間に応じて0°へ戻します。軌道上では進行率・ゲーム日数・着陸地点を動かしません。補正後も惑星間航行と大気圏突入は明示的な操作が必要です。すでにONの自動補正は、操縦席から立っても継続します。

## 操作と所有権

| 操作 | 動作 |
| --- | --- |
| 左右の旋回ボタンを長押し | 毎秒30°で進路偏差を調整。範囲は従来と同じ±60° |
| J / Lを長押し | 左 / 右へ同じ速度で調整。WASD・Q/Eは船内の歩行・見回しとして維持 |
| 短いタップ・ボタンのキーボード操作 | 従来と同じ8°ずつ調整 |
| 手動旋回 | 自動航行をOFFへ切り替え、手動操作を優先 |
| 自動航行ON | 現在の段階を維持しながら進路偏差を補正 |
| 離席・接地確認・着陸完了 | スロットル・旋回・自動航行の変更を拒否 |

操作可否はUIのdisabledだけでなく、ShipJourneyのコマンドでも確認します。入力中の文字欄・選択欄・contenteditable、修飾キー付きショートカットにはJ/Lを割り当てません。

左右の同時入力は相殺し、同方向のキーボードとポインターを併用しても速度を二重加算しません。pointercancel・キャプチャ喪失・ウィンドウのフォーカス喪失・ページ可視状態変更・UI閉鎖・離席・航行インスタンス変更で入力を解除します。押し続けた入力状態は保存せず、既存のheading・autopilot・throttleだけを従来のschemaVersion 2へ保存します。旧SpaceVoyageのクリック操作は維持します。

## 座標・保存への影響

経路・パッド・地域origin・NPC・建物・鉄道の状態は変更しません。調整したheadingは、既存のStarshipEntityを通して船体の表示姿勢へ反映します。軌道上での補正は同じ地点での姿勢変更です。

これは航路に沿う既存のゲームモデルの操作改善です。6自由度の推進・慣性・燃料切れ時の漂流・自由な着陸地点変更は追加していません。スロットルと燃料の進行計算は従来のままで、0%を物理的な停止や惰性飛行として扱いません。
