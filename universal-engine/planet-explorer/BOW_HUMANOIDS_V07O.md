# Universal Engine v0.7o — 弓の縦構え / 人型魔物

2026-10-16

## 弓の縦構え
従来の装備描画は手首のXYZ回転を弓にもかけていたため、腕を前に上げると弓が寝てしまった。新しい `uprightBowTransform` は手首から位置だけを取り、弓の回転にはアバターの進行方向（水平面Yaw）だけを使う。よって弓の上下が常に世界の+Yを向く。矢はv0.7nから引き続き、アバターの+Z（正面）へ水平に進む。操作中の弦の張力・矢のつがえ・射撃アニメーションはそのまま。
