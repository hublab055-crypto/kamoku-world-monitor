# Universal Engine — v0.7 設計・実装計画

> **v0.7bは60関節に加えて着せ替えと表情の実験版まで実装済みです。** v0.7全体の機能はまだ未完成です。 現在プレイ可能なのはv0.6の[3D惑星探索](../../planet-explorer/)と[オリジナルモデル工房](../../model-lab/)です。

## v0.7で実現する体験

1. **人物に感情移入できる** — 21→60関節、自然な歩行/走行/ジャンプ、体の重心移動、表情/まばたき/視線。
2. **自分だけの姿にできる** — 職業に限定しない衣装10プリセット、服レイヤー、髪・顔・体格・染色。
3. **好きな視点で世界を見る** — 旧カメラ/追従/肩越し/自由/注視/高高度俯瞰の6モード。100m〜10kmでも自分の位置をマーカーで確認。
4. **世界に遠くまで眺望がある** — 地形に基づく山脈・海岸・谷・川・地平線、フレーム負荷を制御するLOD。
5. **将来の生活と村づくりにつながる** — 建物/部屋/家具/住人/コミュニティのIDと座標・保存の接続点を定義（v0.8以降で実装）。
