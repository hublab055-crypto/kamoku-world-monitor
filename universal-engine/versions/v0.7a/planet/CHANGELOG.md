# Planet subsystem — Changes

## 0.2.0 — 2026-10-16
- Created independent orbital/planet model: self-rotation, revolution around a star, axial tilt, solar/daylight direction, surface gravity.
- Procedural seeded sphere terrain: ocean/continents/islands, altitude/biomes and stylized rivers; local wetland.
- Simplified climate: temperature, clouds, rain/snow, latitude/season/altitude.
- Bounded seeded trees and grass seed-dispersal/growth; human/deer/fish placeholders; simple resource collection.
- Stone and arrow ballistic trajectory integration with gravity and approximate drag.
- Browser-only dependency-free Canvas globe and local simulation demo, manual time and gravity control, persisted state.
- Added Node automated tests and API/limitation documentation.
- Existing `core.mjs`, Frontier World, Kamoku Monitor, and all pre-existing files remain untouched.
