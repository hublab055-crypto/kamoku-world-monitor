# Universal Engine — v0.6 frozen release

**Launch:** [v0.6 Planet Explorer](./planet-explorer/) | [v0.6 Model Lab](./model-lab/) | [Return to new version](../../planet-explorer/)

This is a frozen copy of the entire v0.6 executable environment. The Git tree contains copies of the original simulation core, planet modules, terrain, avatar geometry, 12 GLB binary models, model laboratory and all three previously working demos. Reused blobs are identical to the original v0.6 release, except the planet-explorer HTML has a clearly visible link to the new release.

**Source branch:** [universal-engine-v0.6-stable](https://github.com/hublab055-crypto/kamoku-world-monitor/tree/universal-engine-v0.6-stable) at commit `82da310c33c87526aebac5932ca43978bfe0fdf3`.

**Saved state:** v0.6 uses `universal-engine:explorer:v1`. v0.7a must use a different key so your old progress is never overwritten. The version switch uses navigation, not a forced import of save data.

**Important:** Browser data clearing removes both local saves even though the keys differ; export future save files before deleting browser data. This copy does not use v0.7 modules.
