# Universal Engine — Changelog

## 0.1.0 — 2026-10-15

- New independent \`universal-engine/\` namespace.
- Added standalone ECMAScript multiverse core: world isolation, entity/component data, event buses, ordered systems, fixed-step clocks, and versioned JSON save/restore.
- Added a responsive browser demo simulating two fictional worlds independently, with playback, independent pause, manual steps, browser-local save, reload, and reset.
- Added Node built-in automated tests and written architecture/API specification.
- No modifications to Kamoku Monitor, Frontier World, root page, existing pipelines, or original save formats.
